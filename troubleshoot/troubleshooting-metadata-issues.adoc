= StorageGRID でメタデータの問題のトラブルシューティング
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
メタデータに問題が発生した場合、アラートによって問題の原因と推奨される対処方法が通知されます。特に、Low metadata storage アラートがトリガーされた場合は、新しい Storage Node を追加する必要があります。

.開始する前に
link:../admin/web-browser-requirements.html["対応ウェブブラウザ"] を使用して Grid Manager にサインインしています。

.タスク概要
発生したメタデータ関連のアラートごとに、推奨される対応策に従ってください。*Low metadata storage* アラートがトリガーされた場合は、新しいストレージノードを追加する必要があります。

StorageGRID は、各ストレージノードのボリューム 0 上に、オブジェクトメタデータ用に一定量の領域を確保します。この領域は「実際の予約領域」と呼ばれ、オブジェクトメタデータ用に割り当てられた領域（許可されたメタデータ領域）と、圧縮や修復などの重要なデータベース操作に必要な領域に細分化されます。許可されたメタデータ領域によって、オブジェクト全体の容量が決まります。

image:metadata_allowed_space_volume_0.png["メタデータ許容容量 Volume 0"]

オブジェクトのメタデータがメタデータ用に割り当てられた容量の100%以上を消費すると、データベース操作が効率的に実行できなくなり、エラーが発生します。

link:../monitor/monitoring-storage-capacity.html#monitor-object-metadata-capacity-for-each-storage-node["各ストレージノードのオブジェクトメタデータ容量を監視する"]を使用して、エラーを事前に予測し、発生する前に修正することができます。

StorageGRID は、許可されたメタデータ領域がどの程度使用されているかを測定するために、以下の Prometheus メトリックを使用します。

[listing]
----
storagegrid_storage_utilization_metadata_bytes/storagegrid_storage_utilization_metadata_allowed_bytes
----
このPrometheus式が特定のしきい値に達すると、*Low metadata storage* アラートがトリガーされます。

* *Minor*: オブジェクトのメタデータが、許可されているメタデータ領域の70%以上を使用しています。できるだけ早く新しい Storage Node を追加してください。
* *重大な問題*: オブジェクトのメタデータが、許可されているメタデータ領域の90%以上を使用しています。新しいストレージノードを直ちに追加する必要があります。
+

CAUTION: オブジェクトのメタデータが許可されているメタデータ容量の90%以上を使用している場合、ダッシュボードに警告が表示されます。この警告が表示された場合は、直ちに新しいストレージノードを追加する必要があります。オブジェクトのメタデータが、許可された容量の100%を超えることがあってはなりません。

* *Critical*: オブジェクトメタデータが許可されたメタデータ領域の100%以上を使用しており、基本的なデータベース操作に必要な領域を消費し始めています。新規オブジェクトの取り込みを停止し、直ちに新しいストレージノードを追加する必要があります。



CAUTION: ボリューム 0 のサイズがメタデータ予約領域ストレージ オプションよりも小さい場合（たとえば、非本番環境の場合）、*メタデータ ストレージ不足* アラートの計算が不正確になる可能性があります。

.手順
. 「アラート」 > 「現在」を選択してください。
. アラート一覧表から、必要に応じて *Low metadata storage* アラートグループを展開し、表示する特定のアラートを選択します。
. 警告ダイアログボックスの詳細を確認してください。
. 重大または致命的な「メタデータストレージ不足」アラートがトリガーされた場合は、直ちにストレージノードを追加する拡張を実行してください。
+

NOTE: StorageGRID は各サイトにすべてのオブジェクトメタデータの完全なコピーを保持するため、グリッド全体のメタデータ容量は最小サイトのメタデータ容量によって制限されます。1 つのサイトにメタデータ容量を追加する必要がある場合は、同数のストレージノード分だけ link:../expand/adding-grid-nodes-to-existing-site-or-adding-new-site.html["他のサイトも展開する"] する必要があります。

+
拡張を実行した後、StorageGRID は既存のオブジェクトメタデータを新しいノードに再分配することで、グリッド全体のメタデータ容量が増加します。ユーザーによる操作は不要です。*メタデータストレージ容量不足*アラートは解除されます。
