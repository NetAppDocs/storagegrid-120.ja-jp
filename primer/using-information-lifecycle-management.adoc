= StorageGRID での情報ライフサイクル管理
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
情報ライフサイクル管理（ILM）を使用して、StorageGRID システム内のすべてのオブジェクトの配置、期間、および取り込み動作を制御します。ILM ルールは、StorageGRID がオブジェクトを長期にわたって保存する方法を決定します。1 つ以上の ILM ルールを設定し、それらを ILM ポリシーに追加します。グリッドは同時に複数の有効なポリシーを持つことができます。

ILM ルールでは以下を定義します：

* どのオブジェクトを保存すべきか。ルールはすべてのオブジェクトに適用することも、フィルターを指定してルールを適用するオブジェクトを特定することもできます。例えば、ルールは特定のテナントアカウント、特定の S3 バケット、または特定のメタデータ値に関連付けられたオブジェクトにのみ適用できます。
* 保管の種類と場所。オブジェクトは、Storage Node またはクラウドストレージプールに保存できます。
* 作成されたオブジェクトコピーの種類。コピーはレプリケートまたはイレイジャー コーディングが可能です。
* 複製されたコピーの場合、作成されたコピーの数。
* イレイジャー コーディングされたコピーの場合、使用されるイレイジャー コーディング方式。
* オブジェクトの保存場所とコピーの種類が時間とともに変化すること。
* オブジェクトがグリッドに取り込まれる際に、オブジェクトデータがどのように保護されるか（同期配置またはデュアルコミット）。


オブジェクトのメタデータは ILM ルールによって管理されないことに注意してください。その代わりに、オブジェクトのメタデータは、メタデータストアと呼ばれる Cassandra データベースに保存されます。データの損失を防ぐため、各サイトでオブジェクトのメタデータのコピーが 3 つ自動的に保持されます。



[[example-ilm-rule]]
== ILMルールの例

例えば、ILM ルールでは以下のように指定できます。

* テナントAに属するオブジェクトにのみ適用します。
* それらのオブジェクトの複製を2つ作成し、それぞれを別のサイトに保管してください。
* 2つのコピーを「永久に」保管するということは、StorageGRID が自動的に削除することはありません。その代わり、StorageGRID はクライアントからの削除要求またはバケットのライフサイクルの期限切れによって削除されるまで、これらのオブジェクトを保持します。
* 取り込み動作にはバランスオプションを使用します。テナント A がオブジェクトを StorageGRID に保存するとすぐに、2 サイト配置指示が適用されます。ただし、必要な両方のコピーをすぐに作成できない場合は除きます。
+
例えば、テナント A がオブジェクトを保存する際にサイト 2 にアクセスできない場合、StorageGRID はサイト 1 のストレージノード上に 2 つの暫定コピーを作成します。サイト 2 が利用可能になり次第、StorageGRID はそのサイトで必要なコピーを作成します。





[[how-an-ilm-policy-evaluates-objects]]
== ILMポリシーがオブジェクトを評価する方法

StorageGRID システムのアクティブな ILM ポリシーは、すべてのオブジェクトの配置、期間、および取り込み動作を制御します。

クライアントがオブジェクトを StorageGRID に保存すると、オブジェクトはアクティブなポリシー内の順序付けられた ILM ルールセットに対して、次のように評価されます。

. ポリシー内の最初のルールのフィルタがオブジェクトに一致する場合、そのオブジェクトはそのルールの取り込み動作に従って取り込まれ、そのルールの配置指示に従って保存されます。
. 最初のルールのフィルタがオブジェクトと一致しない場合、一致するルールが見つかるまで、そのオブジェクトはポリシー内の後続の各ルールに対して評価されます。
. オブジェクトに一致するルールがない場合、ポリシー内のデフォルトルールの取り込み動作と配置手順が適用されます。デフォルトルールはポリシーの最後のルールであり、フィルタを使用することはできません。すべてのテナント、すべてのバケット、およびすべてのオブジェクトバージョンに適用する必要があります。




[[example-ilm-policy]]
== ILMポリシーの例

例えば、ILMポリシーには、以下の内容を指定する3つのILMルールが含まれる場合があります。

* *ルール1：テナントA向けの複製コピー*
+
** テナントAに属するすべてのオブジェクトを一致させます。
** これらのオブジェクトを、3か所のサイトにレプリケートされた3つのコピーとして保存します。
** 他のテナントに属するオブジェクトはルール 1 に一致しないため、ルール 2 に基づいて評価されます。


* *ルール2：1 MBを超えるオブジェクトに対するイレイジャー コーディング*
+
** 他のテナントのすべてのオブジェクトを照合しますが、サイズが1 MBを超えるものに限ります。これらの大型オブジェクトは、3つのサイトで6+3イレイジャー コーディングを使用して保管されます。
** 1 MB以下のオブジェクトには一致しないため、これらのオブジェクトはルール3に基づいて評価されます。


* *ルール3：2コピー、2データセンター*（デフォルト）
+
** これはポリシーにおける最後のデフォルトルールです。フィルターは使用しません。
** ルール1またはルール2に一致しないすべてのオブジェクト（テナントAに属さず、サイズが1 MB以下のオブジェクト）の複製コピーを2つ作成します。
