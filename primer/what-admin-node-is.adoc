= StorageGRID 管理ノードとは何ですか？
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
管理ノードは、システム構成、監視、ログ記録などの管理サービスを提供します。管理ノードは、S3クライアントのトラフィックのロード バランシングにも使用できます。各グリッドには、1つのプライマリ管理ノードが必要であり、冗長性のために任意の数の非プライマリ管理ノードを持つことができます。



[[differences-between-primary-and-non-primary-admin-nodes]]

[[preferred-senderpreferred-sender-admin-node]]
== [[preferred-sender]]優先送信者管理者ノード

StorageGRID の導入環境に複数の管理ノードが含まれている場合、プライマリ管理ノードはアラート通知、AutoSupport パッケージ、および SNMP トラップと通知の優先送信者となります。

通常のシステム運用では、優先送信者のみが通知を送信します。ただし、他のすべての管理ノードは優先送信者を監視します。問題が検出された場合、他の管理ノードが待機送信者として機能します。

以下のような場合には、複数の通知が送信される可能性があります。

* 管理ノードが互いに「孤立」した場合、優先送信者と待機送信者の両方が通知を送信しようとし、通知のコピーが複数受信される可能性があります。
* 待機送信者が優先送信者に問題があることを検知し、通知の送信を開始すると、優先送信者は通知を送信する機能を回復する可能性があります。この場合、通知が重複して送信される可能性があります。待機送信者は、優先送信者でエラーが検出されなくなった時点で通知の送信を停止します。
+

NOTE: AutoSupport パッケージをテストすると、すべての管理ノードがテストを送信します。アラート通知をテストする際は、接続性を確認するために、すべての管理ノードにサインインする必要があります。





[[primary-services-for-admin-nodes]]
== 管理ノードの主要サービス

以下の表は、管理ノードの主要サービスを示していますが、すべてのノードサービスが網羅されているわけではありません。

[cols="1a,2a"]
|===
| サービス | 主要機能 


 a| 
[[ams]]監査管理システム（AMS）
 a| 
システムのアクティビティとイベントを追跡します。



 a| 
[[cmn]]構成管理ノード（CMN）
 a| 
システム全体の構成を管理します。



 a| 
[[high-availability]]高可用性
 a| 
管理ノードおよびゲートウェイノードのグループ向けに、高可用性の仮想IPアドレスを管理します。

*注:* このサービスはゲートウェイノードでも利用可能です。



 a| 
[[load-balancer]]ロード バランサー
 a| 
クライアントからストレージノードへの S3 トラフィックのロード バランシングを提供します。

*注:* このサービスはゲートウェイノードでも利用可能です。



 a| 
[[mgmt-api]]管理アプリケーションプログラミングインターフェース（mgmt-api）
 a| 
グリッド管理APIおよびテナント管理APIからのリクエストを処理します。



 a| 
[[nms]]ネットワーク管理システム（NMS）
 a| 
グリッドマネージャーの機能を提供します。



 a| 
[[prometheus]]Prometheus
 a| 
すべてのノード上のサービスから時系列メトリクスを収集し、保存します。



 a| 
[[ssm]]サーバー状態モニター（SSM）
 a| 
オペレーティングシステムおよび基盤となるハードウェアを監視します。

|===
