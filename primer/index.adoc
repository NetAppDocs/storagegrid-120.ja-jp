= StorageGRID とは何ですか？
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp® StorageGRID® は、パブリック、プライベート、ハイブリッドマルチクラウド環境における幅広いユースケースをサポートする、ソフトウェアで定義されるオブジェクトストレージスイートです。StorageGRID は Amazon S3 API のネイティブサポートを提供し、自動化されたライフサイクル管理などの業界をリードする革新的な機能により、非構造化データを長期間にわたってコスト効率よく保存、セキュリティ保護、保護、および保全します。

StorageGRID は、大規模な非構造化データに対して、安全で耐久性のあるストレージを提供します。統合されたメタデータ駆動型のライフサイクル管理ポリシーは、データのライフサイクル全体を通して、データがどこに保存されるかを最適化します。コスト削減のため、コンテンツは適切な場所に、適切なタイミングで、適切なストレージ階層に配置されます。

StorageGRID は、地理的に分散した冗長な異種ノードで構成されており、既存および次世代のクライアント アプリケーションと統合できます。

== StorageGRID のメリット

StorageGRID システムの利点には、以下のものが含まれます。

* 大規模に拡張可能で使いやすい、非構造化データ向けの地理的に分散したデータ リポジトリです。
* Amazon Web Services Simple Storage Service（S3）標準オブジェクト ストレージ プロトコル。
* ハイブリッドクラウド対応。ポリシーベースの情報ライフサイクル管理（ILM）は、Amazon Web Services（AWS）やMicrosoft Azureなどのパブリッククラウドにオブジェクトを保存します。StorageGRIDプラットフォームサービスにより、パブリッククラウドに保存されたオブジェクトのコンテンツ複製、イベント通知、およびメタデータ検索が可能になります。
* 耐久性と可用性を確保するための柔軟なデータ保護。データはレプリケーションと階層化されたイレイジャー コーディングを使用して保護できます。保存時および転送時のデータ検証により、長期保存におけるデータの完全性が確保されます。
* ストレージコストの管理を支援する動的なデータのライフサイクル管理。ILM ルールを作成して、オブジェクトレベルでデータのライフサイクルを管理し、データの局所性、耐久性、パフォーマンス、コスト、および保持期間をカスタマイズできます。
* データストレージと一部の管理機能の高可用性、および StorageGRID リソース全体のデータ負荷を最適化する統合ロード バランシング。
* 複数のストレージテナントアカウントをサポートし、システムに保存されているオブジェクトを異なるエンティティごとに分離できます。
* StorageGRID システムの健全性を監視するための多数のツール（包括的なアラートシステム、グラフィカルなダッシュボード、およびすべてのノードとサイトの詳細なステータスを含む）。
* ソフトウェアまたはハードウェアベースの展開をサポートします。StorageGRID は次のいずれかに展開できます：
+
** VMware上で動作する仮想マシン。
** Linuxホスト上のコンテナエンジン。
** StorageGRID 対応アプライアンス。
+
*** ストレージ アプライアンスは、オブジェクト ストレージを提供します。
*** サービスアプライアンスは、グリッド管理およびロード バランシングサービスを提供します。




* これらの規制の関連するストレージ要件に準拠しています。
+
** 証券取引委員会（SEC）は、取引所会員、ブローカー、ディーラーを規制する17 CFR § 240.17a-4(f)を定めています。
** 金融業界規制機構（FINRA）規則4511(c)は、SEC規則17a-4(f)の形式およびメディア要件に従います。
** 商品先物取引委員会（CFTC）は、商品先物取引を規制する規則17 CFR § 1.31(c)-(d)を定めている。


* 業務に支障をきたさないアップグレードおよびメンテナンス作業。アップグレード、拡張、廃止、およびメンテナンスの手順中も、コンテンツへのアクセスを維持します。
* フェデレーション型ID管理。ユーザ認証のために、Active Directory、OpenLDAP、またはOracle Directory Serviceと統合します。Security Assertion Markup Language 2.0（SAML 2.0）標準を使用して、StorageGRIDとActive Directory Federation Services（AD FS）の間で認証および認可データを交換するシングル サインオン（SSO）をサポートします。
