= StorageGRIDによるオブジェクト取得の処理方法
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
取得操作は、StorageGRID システムとクライアント間の定義されたデータフローで構成されます。システムは属性を使用して、ストレージノード、または必要に応じてクラウドストレージプールからのオブジェクトの取得を追跡します。

ストレージノードのLDRサービスは、メタデータストアにオブジェクトデータの場所を問い合わせ、ソースLDRサービスからデータを取得します。データ取得は、ストレージノードから行うことが優先されます。オブジェクトがストレージノード上に存在しない場合、取得要求はクラウドストレージプールに送信されます。


NOTE: オブジェクトのコピーが AWS Glacier ストレージまたは Azure Archive 層にのみ存在する場合、クライアント アプリケーションは S3 RestoreObject リクエストを発行して、クラウドストレージプールに取得可能なコピーを復元する必要があります。

image:retrieve_data_flow.png["取得する"]

. LDRサービスは、クライアントアプリケーションから取得要求を受信します。
. LDRサービスは、メタデータストアに対してオブジェクトデータの場所とメタデータを照会します。
. LDRサービスは、取得要求をソースLDRサービスに転送します。
. ソースLDRサービスは、照会先のLDRサービスからオブジェクトデータを返し、システムはそのオブジェクトをクライアントアプリケーションに返します。
