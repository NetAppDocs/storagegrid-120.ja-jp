= StorageGRID でのオブジェクトのライフサイクル
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
オブジェクトのライフサイクルはさまざまな段階で構成されています。各段階は、オブジェクトに対して実行される操作を表しています。

オブジェクトのライフサイクルには、取り込み、コピー管理、取得、削除といった操作が含まれます。

* *取り込み*：S3クライアントアプリケーションがHTTP経由でオブジェクトをStorageGRIDシステムに保存するプロセス。この段階では、StorageGRIDシステムがオブジェクトの管理を開始します。
* *コピー管理*：StorageGRID で複製されたコピーとイレイジャー コーディングされたコピーを管理するプロセス。有効な ILM ポリシーの ILM ルールに従って管理されます。コピー管理段階では、StorageGRID はストレージノードまたは Cloud Storage Pool 上に指定された数と種類のオブジェクトコピーを作成および維持することにより、オブジェクトデータの損失を防ぎます。
* *取得*：クライアントアプリケーションが StorageGRID システムによって保存されたオブジェクトにアクセスするプロセス。クライアントは、ストレージノードまたはクラウドストレージプールから取得したオブジェクトを読み取ります。
* *削除*：グリッドからすべてのオブジェクトのコピーを削除するプロセス。オブジェクトは、クライアント アプリケーションが StorageGRID システムに削除リクエストを送信した結果として、またはオブジェクトの有効期間が終了したときに StorageGRID が実行する自動処理の結果として削除されることがあります。
