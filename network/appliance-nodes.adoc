= StorageGRIDアプライアンス ノードのネットワーク構成
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRIDアプライアンスのネットワークポートを、スループット、冗長性、フェイルオーバーの要件を満たすポートボンディングモードを使用するように設定できます。

StorageGRID アプライアンスの 10/25-GbE ポートは、グリッドネットワークおよびクライアントネットワークへの接続に対して、固定ボンディングモードまたはアグリゲートボンディングモードで構成できます。

1GbE管理ネットワークポートは、管理ネットワークへの接続用に、独立モードまたはアクティブ/バックアップモードに設定できます。

お使いの機器のポートボンディングモードに関する情報をご覧ください。
