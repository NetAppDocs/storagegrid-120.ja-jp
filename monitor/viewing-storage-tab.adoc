= StorageGRID ストレージタブを表示します
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージタブには、ストレージの可用性とその他のストレージ指標が表示されます。

ストレージタブは、すべてのノード、各サイト、およびグリッド全体に対して表示されます。



[[storage-used-graphs]]
== ストレージ使用量グラフ

ストレージノード、各サイト、およびグリッド全体について、「ストレージ」タブには、オブジェクトデータとオブジェクトメタデータによって時間の経過とともにどれだけのストレージが使用されているかを示すグラフが含まれています。


NOTE: ノードがグリッドに接続されていない場合（アップグレード中や切断状態など）、特定のメトリックが利用できないか、サイトおよびグリッドの合計値から除外される可能性があります。ノードがグリッドに再接続した後、値が安定するまで数分間お待ちください。

image:nodes_storage_node_storage_tab.png["ノード > ストレージノード > ストレージタブ"]



[[disk-devices-volumes-and-object-stores-tables]]
== ディスクデバイス、ボリューム、およびオブジェクトストアのテーブル

すべてのノードにおいて、「ストレージ」タブには、そのノード上のディスクデバイスとボリュームの詳細が表示されます。ストレージノードの場合、オブジェクトストアテーブルには各ストレージボリュームに関する情報が表示されます。

image:nodes_page_storage_tables.png["ノード ページ ストレージ テーブル"]
