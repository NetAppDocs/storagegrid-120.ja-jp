= StorageGRIDでS3クライアント操作を監視する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
オブジェクトの取り込み速度と取得速度、およびオブジェクト数、クエリ、検証に関する指標を監視できます。クライアントアプリケーションによる StorageGRID システムでのオブジェクトの読み取り、書き込み、変更の成功および失敗の試行回数を表示できます。

.開始する前に
link:../admin/web-browser-requirements.html["対応ウェブブラウザ"] を使用して Grid Manager にサインインしています。

.手順
. ダッシュボードから「パフォーマンス」タブを選択します。
. S3チャートを参照してください。これらのチャートは、選択した期間中にストレージノードによって実行されたクライアント操作の数と、ストレージノードが受信したAPIリクエストの数をまとめたものです。
. *ノード*を選択して、ノードページにアクセスします。
. ノードのホーム画面（グリッドレベル）から、「オブジェクト」タブを選択します。
+
このグラフは、StorageGRID システム全体の S3 取り込みおよび取得レートを1秒あたりのバイト数で示しており、取り込まれたデータまたは取得されたデータの量も表示されます。時間間隔を選択するか、カスタム間隔を適用できます。

. 特定のストレージノードの情報を表示するには、左側のリストからノードを選択し、「オブジェクト」タブを選択します。
+
このグラフは、ノードのデータ取り込み速度とデータ取得速度を示しています。このタブには、オブジェクト数、メタデータクエリ、検証操作に関する指標も含まれています。

+
