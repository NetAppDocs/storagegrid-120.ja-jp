= StorageGRID プラットフォームサービスタブを表示します
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
プラットフォームサービスタブには、サイトにおけるS3プラットフォームサービスの運用に関する情報が表示されます。

各サイトに「プラットフォームサービス」タブが表示されます。このタブでは、CloudMirrorレプリケーションや検索統合サービスなど、S3 プラットフォームサービスに関する情報を確認できます。このタブのグラフには、保留中のリクエスト数、リクエスト完了率、リクエスト失敗率などの指標が表示されます。

image:nodes_page_site_level_platform_services.gif["ノードページサイトレベルのプラットフォームサービス"]

S3プラットフォームサービスに関する詳細情報（トラブルシューティングの詳細を含む）については、link:../admin/index.html["StorageGRID の管理手順"]を参照してください。
