= StorageGRID でアラート通知をサイレンス
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
必要に応じて、アラート通知を一時的に抑制するサイレンスを設定できます。

.開始する前に
* link:../admin/web-browser-requirements.html["対応ウェブブラウザ"] を使用して Grid Manager にサインインしています。
* あなたはlink:../admin/admin-group-permissions.html["アラートの管理またはルートアクセス権限"]を持っています。


.タスク概要
グリッド全体、単一サイト、または単一ノードに対して、1つまたは複数の重要度レベルでアラートルールを無効化できます。サイレンスを設定すると、単一のアラートルール、またはすべてのアラートルールに関する通知がすべて抑制されます。

SNMPエージェントを有効にしている場合、サイレンス設定はSNMPトラップとインフォームも抑制します。


CAUTION: アラートルールを無効化する際は、慎重に判断してください。アラートをミュートすると、重要な操作の完了を妨げるまで、根本的な問題に気づかない可能性があります。

.手順
. 「アラート」＞「サイレンス」を選択します。
+
Silences ページが表示されます。

+
image:alerts_silences_page.png["アラート > サイレンスページ"]

. *Create*を選択します。
+
「無音の作成」ダイアログボックスが表示されます。

+
image:alerts_create_silence.png["アラート > サイレンスを作成"]

. 以下の情報を選択または入力してください。
+
[cols="1a,3a"]
|===
| フィールド | 説明 


 a| 
アラートルール
 a| 
停止させたいアラートルールの名前。アラートルールが無効になっている場合でも、デフォルトまたはカスタムのアラートルールを選択できます。

*注：* このダイアログボックスで指定した条件を使用してすべてのアラートルールをサイレントにする場合は、*すべてのルール*を選択してください。



 a| 
説明
 a| 
任意で、サイレンスの説明を入力します。例えば、このサイレンスの目的を説明します。



 a| 
Duration
 a| 
このサイレンスを有効にしておく期間を、分、時間、または日単位で指定してください。サイレンスの有効期間は5分から1,825日（5年間）まで設定できます。

*注:* アラートルールを長期間サイレンスにしないでください。アラートルールがサイレンスになっている場合、重要な操作の完了を妨げるまで、根本的な問題を検出できない可能性があります。ただし、*サービスアプライアンスのリンクダウン*アラートや*ストレージアプライアンスのリンクダウン*アラートのように、特定の意図的な構成によってアラートがトリガーされる場合は、長期間のサイレンスを使用する必要があるかもしれません。



 a| 
重大度
 a| 
ミュートするアラートの重大度を選択してください。選択した重大度のいずれかでアラートがトリガーされた場合、通知は送信されません。



 a| 
ノード
 a| 
このサイレンスを適用するノードを指定します。グリッド全体、単一サイト、または単一ノードに対して、アラートルールまたはすべてのルールを抑制することができます。グリッド全体を選択した場合、すべてのサイトとすべてのノードにサイレンスが適用されます。サイトを選択した場合、そのサイトのノードのみにサイレンスが適用されます。

*注:* 1つのサイレンスに対して、複数のノードまたは複数のサイトを選択することはできません。複数のノードまたは複数のサイトで同時に同じアラートルールを抑制したい場合は、追加のサイレンスを作成する必要があります。

|===
. * 保存 * を選択します。
. サイレンスの期限が切れる前に変更または終了したい場合は、編集または削除できます。
+
[cols="1a,3a"]
|===
| オプション | 説明 


 a| 
無音を編集する
 a| 
.. 「アラート」＞「サイレンス」を選択します。
.. 表から、編集したいサイレンスのラジオボタンを選択します。
.. *Edit*を選択します。
.. 説明、残り時間、選択した重大度、または影響を受けるノードを変更します。
.. * 保存 * を選択します。




 a| 
無音部分を削除する
 a| 
.. 「アラート」＞「サイレンス」を選択します。
.. 表から、削除したいサイレンスのラジオボタンを選択します。
.. *削除*を選択します。
.. この無音部分を削除することを確認するには、*OK* を選択してください。
+
*注*: このアラートがトリガーされると、通知が送信されます（他のサイレンスによって抑制されない限り）。このアラートが現在発生している場合、メールまたはSNMP通知が送信され、アラートページが更新されるまでに数分かかる場合があります。



|===
