= StorageGRID ソフトウェアログ
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID ログを使用して問題のトラブルシューティングを行うことができます。


NOTE: ログを外部のsyslogサーバーに送信する場合や、 `bycast.log`や `nms.log`などの監査情報の送信先を変更する場合は、link:../monitor/configure-log-management.html["ログ管理の設定"]を参照してください。



[[general-storagegrid-logs]]
== 一般的なStorageGRIDログ

[cols="3a,3a,2a"]
|===
| ファイル名 | Notes | 発見場所 


| /var/local/log/bycast.log  a| 
StorageGRID の主要なトラブルシューティングファイルです。
 a| 
すべてのノード



| /var/local/log/bycast-err.log  a| 
サブセットを含む `bycast.log`（重大度がERRORおよびCRITICALのメッセージ）。CRITICALメッセージはシステムにも表示されます。
 a| 
すべてのノード



| /var/local/core/  a| 
プログラムが異常終了した場合に作成されるコアダンプファイルが含まれます。考えられる原因としては、アサーションの失敗、違反、またはスレッドのタイムアウトなどが挙げられます。

*注*: ファイル ``/var/local/core/kexec_cmd`は通常、アプライアンスノードに存在し、エラーを示すものではありません。
 a| 
すべてのノード

|===

[[nms-logs]]
== NMSログ

[cols="3a,3a,2a"]
|===
| ファイル名 | Notes | 発見場所 


| /var/local/log/nms.log  a| 
* グリッドマネージャーとテナントマネージャーからの通知を取得します。
* NMSサービスの運用に関連するイベントを記録します。例えば、メール通知や設定変更などです。
* システムで行われた構成変更の結果として生じた XML バンドルの更新が含まれています。
* 1日に1回実行される属性ダウンサンプリングに関連するエラーメッセージが含まれています。
* Javaウェブサーバーのエラーメッセージ（ページ生成エラーやHTTP Status 500エラーなど）が含まれています。
* AutoSupport に関連するログが含まれています。

 a| 
管理ノード



| /var/local/log/nms.errlog  a| 
MySQLデータベースのアップグレードに関連するエラーメッセージが含まれています。

対応するサービスの標準エラー出力（stderr）ストリームが含まれています。サービスごとにログファイルが1つあります。サービスに問題がない限り、これらのファイルは通常空です。
 a| 
管理ノード



| /var/local/log/nms.requestlog  a| 
管理APIから内部 StorageGRID サービスへの発信接続に関する情報が含まれています。
 a| 
管理ノード

|===
