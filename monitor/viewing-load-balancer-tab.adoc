= StorageGRID ロード バランサタブを表示します
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ロード バランシング タブには、ロード バランシング サービスの動作に関連するパフォーマンス グラフと診断グラフが表示されます。

ロード バランサータブは、管理ノードとゲートウェイノード、各サイト、およびグリッド全体に対して表示されます。各サイトについて、ロード バランサータブには、そのサイトにあるすべてのノードの統計情報の集計概要が表示されます。グリッド全体について、ロード バランサータブには、すべてのサイトの統計情報の集計概要が表示されます。

ロード バランシング サービスを介して I/O が実行されていない場合、またはロード バランサーが設定されていない場合は、グラフに「データなし」と表示されます。

image:nodes_page_load_balancer_tab.png["ノードページ ロード バランシング タブ"]



[[request-traffic]]
== リクエスト ネットワーク トラフィック

このグラフは、ロード バランシングのエンドポイントとリクエストを行うクライアント間で送信されるデータのスループットを、ビット/秒単位で3分間移動平均したものです。


NOTE: この値は、各リクエストの完了時に更新されます。そのため、この値はリクエストレートが低い場合や、リクエストの処理時間が非常に長い場合のリアルタイム スループットとは異なる場合があります。現在のネットワーク トラフィックの動作状況をより正確に把握するには、「Network」タブを参照してください。



[[incoming-request-rate]]
== 受信リクエスト率

このグラフは、リクエストの種類（GET、PUT、HEAD、DELETE）別に分類した、1秒あたりの新規リクエスト数の3分移動平均を示しています。この値は、新しいリクエストのヘッダーが検証されたときに更新されます。



[[average-request-duration-non-error]]
== 平均リクエスト処理時間（エラーを除く）

このグラフは、リクエストの種類（GET、PUT、HEAD、DELETE）別に分類した、リクエスト処理時間の3分移動平均を示しています。各リクエストの処理時間は、ロード バランシング サービスがリクエストヘッダーを解析した時点から始まり、完全なレスポンスボディがクライアントに返された時点で終了します。



[[error-response-rate]]
== エラー応答率

このグラフは、エラー応答コード別に分類した、クライアントに返されたエラー応答数の3分移動平均を1秒あたりで示しています。
