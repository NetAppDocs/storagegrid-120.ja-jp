= StorageGRID システムを監視する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID システムが期待どおりに動作していることを確認するために、定期的に監視してください。

.開始する前に
* link:../admin/web-browser-requirements.html["対応ウェブブラウザ"] を使用して Grid Manager にサインインしています。
* link:../admin/admin-group-permissions.html["特定のアクセス権限"]があります。



NOTE: グリッドマネージャに表示されるストレージ値の単位を変更するには、グリッドマネージャの右上にあるユーザードロップダウンを選択し、*ユーザー設定*を選択します。
