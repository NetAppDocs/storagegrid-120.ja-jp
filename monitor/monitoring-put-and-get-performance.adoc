= StorageGRIDでPUTおよびGETのパフォーマンスを監視
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
オブジェクトの保存や取得といった特定の操作のパフォーマンスを監視することで、さらなる調査が必要となる可能性のある変更点を特定するのに役立ちます。

.タスク概要
PUTおよびGETのパフォーマンスを監視するには、ワークステーションから直接S3コマンドを実行するか、オープンソースのS3testerアプリケーションを使用できます。これらの方法を使用すると、クライアントアプリケーションの問題や外部ネットワークの問題など、StorageGRIDの外部要因とは独立してパフォーマンスを評価できます。

PUTおよびGET操作のテストを実施する際は、以下のガイドラインに従ってください。

* グリッドに取り込むオブジェクトと同程度のオブジェクトサイズを使用してください。
* ローカルサイトとリモートサイトの両方に対して操作を実行します。


link:../audit/index.html["監査ログ"]のメッセージは、特定の操作を実行するのに必要な合計時間を示します。例えば、S3 GET リクエストの総処理時間を確認するには、SGET 監査メッセージの TIME 属性の値を参照してください。以下の S3 操作の監査メッセージにも TIME 属性が含まれています：DELETE、GET、HEAD、Metadata Updated、POST、PUT

結果を分析する際は、リクエストを処理するのにかかる平均時間と、達成可能な全体的なスループットの両方を確認してください。定期的に同じテストを繰り返し、結果を記録することで、調査が必要となる可能性のある傾向を特定できます。

*  https://github.com/s3tester["S3testerをGitHubからダウンロード"^]できます。
