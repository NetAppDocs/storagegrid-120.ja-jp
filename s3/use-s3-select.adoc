= StorageGRID でサポートされている Amazon S3 Select 操作
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID は、link:select-object-content.html["SelectObjectContent コマンド"]に対して以下の Amazon S3 Select 句、データ型、および演算子をサポートしています。


NOTE: 記載されていない項目はサポート対象外です。

構文については、link:select-object-content.html["SelectObjectContent"]を参照してください。S3 Selectの詳細については、 https://docs.aws.amazon.com/AmazonS3/latest/userguide/selecting-content-from-objects.html["S3 SelectのAWSドキュメント"^]を参照してください。

S3 Select が有効になっているテナントアカウントのみが SelectObjectContent クエリを発行できます。link:../admin/manage-s3-select-for-tenant-accounts.html["S3 Selectを使用する際の考慮事項と要件"] を参照してください。
