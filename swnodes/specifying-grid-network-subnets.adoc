= StorageGRID のグリッドネットワークサブネットを指定します
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
グリッドネットワークで使用するサブネットを指定する必要があります。

.タスク概要
サブネットエントリには、StorageGRIDシステムの各サイトのグリッドネットワークのサブネット、およびグリッドネットワーク経由でアクセス可能にする必要があるすべてのサブネットが含まれます。

グリッドサブネットが複数ある場合は、グリッドネットワークゲートウェイが必要です。指定されたすべてのグリッドサブネットは、このゲートウェイを経由して到達可能である必要があります。

.手順
. *サブネット 1* テキストボックスに、少なくとも 1 つのグリッド ネットワークの CIDR ネットワークアドレスを指定してください。
. 最後のエントリの横にあるプラス記号をクリックすると、ネットワークエントリを追加できます。グリッドネットワーク内のすべてのサイトについて、すべてのサブネットを指定する必要があります。
+
** 既に少なくとも1つのノードをデプロイしている場合は、*グリッドネットワークサブネットの検出*をクリックすると、Grid Managerに登録されているグリッドノードから報告されたサブネットがグリッドネットワークサブネットリストに自動的に表示されます。
** Grid Networkゲートウェイ経由でアクセスするNTP、DNS、LDAP、またはその他の外部サーバーのサブネットは、手動で追加する必要があります。
