= Linux上のStorageGRIDホストサービスのインストールとグリッドノードの構成を自動化
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID ホストサービスのインストールとグリッドノードの設定を自動化できます。

.タスク概要

NOTE: 「Linux」とは、RHEL、Ubuntu、またはDebianのいずれかの環境を指します。サポートされているバージョンの一覧については、 https://imt.netapp.com/matrix/#welcome["NetApp Interoperability Matrix Tool（IMT）"^]を参照してください。

デプロイメントの自動化は、以下のいずれかのケースで役立つ可能性があります。

* Ansible、Puppet、Chef などの標準的なオーケストレーションフレームワークを使用して、物理ホストまたは仮想ホストをデプロイおよび構成している場合。
* 複数の StorageGRID インスタンスをデプロイする予定がある。
* 大規模で複雑な StorageGRID インスタンスをデプロイしています。


StorageGRID ホストサービスはパッケージによってインストールされ、設定ファイルによって制御されます。設定ファイルは、以下のいずれかの方法で作成できます。

* link:creating-node-configuration-files.html["設定ファイルを作成する"]手動インストール中にインタラクティブに操作します。
* この記事で説明するように、標準的なオーケストレーションフレームワークを使用した自動インストールを可能にするために、設定ファイルを事前に（またはプログラムによって）準備してください。
+
StorageGRID は、StorageGRID アプライアンスおよび StorageGRID システム全体（「グリッド」）の設定を自動化するためのオプションの Python スクリプトを提供します。これらのスクリプトを直接使用することも、スクリプトを調べて、自分で開発するグリッドの導入および設定ツールでの link:overview-of-installation-rest-api.html["StorageGRID インストール REST API"] の使用方法を学ぶこともできます。





[[automate-the-installation-and-configuration-of-the-storagegrid-host-service]]
== StorageGRID ホストサービスのインストールと設定を自動化する

Ansible、Puppet、Chef、Fabric、SaltStackなどの標準的なオーケストレーションフレームワークを使用して、StorageGRIDホストサービスのインストールを自動化できます。

StorageGRID ホストサービスは、DEB（Ubuntu または Debian）または RPM（RHEL）パッケージとして提供され、自動インストールを可能にするために事前に（またはプログラムによって）準備できる設定ファイルによって制御されます。Linux デプロイメントのインストールと構成に標準のオーケストレーション フレームワークをすでに使用している場合は、StorageGRID をプレイブックやレシピに追加する作業は簡単に行えます。

ホストの準備と仮想グリッドノードの展開に関するすべての手順を自動化できます。



[[example-ansible-role-and-playbook]]
=== Ansibleロールとプレイブックの例

インストールアーカイブの `/extras`フォルダには、Ansible ロールとプレイブックのサンプルが含まれています。Ansible プレイブックは、 `storagegrid`ロールがホストを準備し、ターゲットサーバーに StorageGRID をインストールする方法を示しています。必要に応じて、ロールやプレイブックをカスタマイズできます。


NOTE: サンプルプレイブックには、StorageGRID ホストサービスを開始する前にネットワークデバイスを作成するために必要な手順は含まれていません。プレイブックを完成させて使用する前に、これらの手順を追加してください。

[role="tabbed-block"]
====
.RHEL
--
RHELの場合、提供されている `storagegrid`ロール例のインストールタスクでは、 `ansible.builtin.dnf`モジュールを使用して、ローカルのRPMファイルまたはリモートのYumリポジトリからインストールを実行します。モジュールが利用できないかサポートされていない場合は、次のファイル内の適切なAnsibleタスクを編集して、 `yum`または `ansible.builtin.yum`モジュールを使用する必要があります：

* `roles/storagegrid/tasks/rhel_install_from_repo.yml`
* `roles/storagegrid/tasks/rhel_install_from_local.yml`


--
.UbuntuまたはDebian
--
Ubuntu または Debian の場合、提供されている `storagegrid`ロールの例のインストールタスクでは、 `ansible.builtin.apt`モジュールを使用して、ローカルの DEB ファイルまたはリモートの apt リポジトリからインストールを実行します。モジュールが利用できないかサポートされていない場合は、次のファイル内の適切な Ansible タスクを編集して、 `ansible.builtin.apt`モジュールを使用する必要があります：

* `roles/storagegrid/tasks/deb_install_from_repo.yml`
* `roles/storagegrid/tasks/deb_install_from_local.yml`


--
====


[[automate-the-configuration-of-storagegrid]]
== StorageGRID の設定を自動化する

グリッドノードをデプロイした後、StorageGRID システムの設定を自動化できます。

.開始する前に
* インストールアーカイブ内の以下のファイルの場所を確認しておいてください。
+
[cols="1a,1a"]
|===
| ファイル名 | 説明 


| configure-storagegrid.py  a| 
設定を自動化するために使用されるPythonスクリプト



| configure-storagegrid.sample.json  a| 
スクリプトで使用する設定ファイルの例



| configure-storagegrid.blank.json  a| 
スクリプトで使用するための空の設定ファイル

|===
* あなたは `configure-storagegrid.json`設定ファイルを作成しました。このファイルを作成するには、サンプル設定ファイル(`configure-storagegrid.sample.json`）または空の設定ファイル(`configure-storagegrid.blank.json`）を変更してください。



CAUTION: 変更後の `configure-storagegrid.json`設定ファイルのパスワードセクションから管理パスワードとプロビジョニングパスフレーズを安全な場所に保存してください。これらのパスワードは、インストール、拡張、およびメンテナンスの手順に必要です。変更後の `configure-storagegrid.json`設定ファイルのバックアップも作成し、安全な場所に保管してください。

.タスク概要
 `configure-storagegrid.py` Python スクリプトと `configure-storagegrid.json` 設定ファイルを使用して、StorageGRID システムの設定を自動化できます。


NOTE: グリッドマネージャーまたはインストールAPIを使用してシステムを設定することもできます。

.手順
. Pythonスクリプトを実行するために使用しているLinuxマシンにログインします。
. インストールアーカイブを展開したディレクトリに移動します。
+
次に例を示します。

+
[listing]
----
cd StorageGRID-Webscale-version/platform
----
+
 `platform`の値は `debs`、 `rpms`、または `vsphere`です。

. Pythonスクリプトを実行し、作成した設定ファイルを使用してください。
+
次に例を示します。

+
[listing]
----
./configure-storagegrid.py ./configure-storagegrid.json --start-install
----


.結果
リカバリパッケージ `.zip`ファイルは設定プロセス中に生成され、インストールおよび設定プロセスを実行しているディレクトリにダウンロードされます。1つ以上のグリッドノードに障害が発生した場合にStorageGRIDシステムを復旧できるよう、リカバリパッケージファイルをバックアップする必要があります。たとえば、セキュアなバックアップ済みネットワーク上の場所と、セキュアなクラウドストレージの場所にコピーしてください。


CAUTION: リカバリパッケージファイルには暗号化キーとパスワードが含まれており、これらを使用して StorageGRID システムからデータを取得できるため、このファイルは保護する必要があります。

ランダムなパスワードを生成するように指定した場合は、 `Passwords.txt`ファイルを開き、StorageGRID システムへのアクセスに必要なパスワードを確認してください。

[listing]
----
######################################################################
##### The StorageGRID "Recovery Package" has been downloaded as: #####
#####           ./sgws-recovery-package-994078-rev1.zip          #####
#####   Safeguard this file as it will be needed in case of a    #####
#####                 StorageGRID node recovery.                 #####
######################################################################
----
確認メッセージが表示されたら、StorageGRID システムのインストールと設定が完了しています。

[listing]
----
StorageGRID has been configured and installed.
----
