= StorageGRIDに必要な情報と資料
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID をインストールする前に、必要な情報と資料を収集して準備してください。



[[required-information]]
== 必須情報

ネットワークプラン:: 各 StorageGRID ノードに接続するネットワーク。StorageGRID は、トラフィックの分離、セキュリティ、および管理上の利便性のために複数のネットワークをサポートしています。
+
--
StorageGRID link:../network/index.html["ネットワーク構築ガイドライン"]を参照してください。

--
ネットワーク情報:: 各グリッドノードに割り当てるIPアドレス、およびDNSサーバーとNTPサーバーのIPアドレス。
グリッドノード用のサーバー:: 合計で、導入予定の StorageGRID ノードの数と種類をサポートするのに十分なリソースを提供するサーバー群（物理サーバー、仮想サーバー、またはその両方）を特定します。
+
--

NOTE: StorageGRID のインストールで StorageGRID アプライアンス（ハードウェア）ストレージノードを使用しない場合は、バッテリ バックアップ式書き込みキャッシュ（BBWC）を備えたハードウェア RAID ストレージを使用する必要があります。StorageGRID は、仮想ストレージエリアネットワーク（vSAN）、ソフトウェア RAID、または RAID 保護なしの使用をサポートしていません。

--
ノード移行（必要に応じてUbuntuおよびDebianのみ）:: サービスの中断なしに物理ホストの定期メンテナンスを実行したい場合は、link:node-container-migration-requirements.html["ノード移行の要件"]を理解してください。
関連情報:: https://imt.netapp.com/matrix/#welcome["NetApp Interoperability Matrix Tool"^]




[[required-materials]]
== 必要な材料

NetApp StorageGRIDライセンス:: デジタル署名された有効なNetAppライセンスが必要です。



NOTE: テストや概念実証グリッドに使用できる非本番ライセンスが、StorageGRID インストールアーカイブに含まれています。

StorageGRIDインストールアーカイブ:: link:downloading-and-extracting-storagegrid-installation-files.html["StorageGRID インストールアーカイブをダウンロードしてファイルを展開します"]。
サービス用ノートパソコン:: StorageGRID システムは、サービス用ノートパソコンを介してインストールされます。
+
--
サービス用ノートパソコンには以下のものが必要です。

* ネットワークポート
* SSHクライアント（例：PuTTY）
* link:../admin/web-browser-requirements.html["対応ウェブブラウザ"]
