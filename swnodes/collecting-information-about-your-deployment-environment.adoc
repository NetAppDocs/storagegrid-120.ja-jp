= StorageGRID用のVMware環境に関する情報を収集
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
グリッドノードをデプロイする前に、ネットワーク構成とVMware環境に関する情報を収集する必要があります。


NOTE: 一部のノードを今インストールし、残りを後でインストールするよりも、すべてのノードを一度にインストールする方が効率的です。



[[vmware-information]]
== VMware情報

デプロイメント環境にアクセスし、VMware環境、グリッドネットワーク、管理ネットワーク、クライアントネットワーク用に作成されたネットワーク、およびストレージノードで使用する予定のストレージボリュームの種類に関する情報を収集する必要があります。

VMware 環境に関する以下の情報を収集する必要があります：

* デプロイメントを完了するための適切な権限を持つ VMware vSphere アカウントのユーザー名とパスワード。
* 各 StorageGRID ノード仮想マシンのホスト、データストア、およびネットワーク構成情報。



NOTE: VMware live vMotionは仮想マシンのクロック時刻がジャンプする原因となり、どのタイプのグリッドノードでもサポートされていません。まれではありますが、クロック時刻が正しくない場合、データの損失や設定の更新エラーが発生する可能性があります。



[[grid-network-information]]
== グリッドネットワーク情報

StorageGRID グリッドネットワーク用に作成された VMware ネットワークに関する情報（必須）を収集する必要があります。収集する情報には以下が含まれます：

* ネットワーク名。
* IPアドレスを割り当てる方法（静的またはDHCP）。
+
** 静的IPアドレスを使用する場合は、各グリッドノードに必要なネットワークの詳細（IPアドレス、ゲートウェイ、ネットワークマスク）。
** DHCPを使用している場合は、グリッドネットワーク上のプライマリ管理ノードのIPアドレスを指定します。詳細については、link:how-grid-nodes-discover-primary-admin-node.html["グリッドノードがプライマリ管理ノードを検出する方法"]を参照してください。






[[admin-network-information]]
== 管理者ネットワーク情報

オプションの StorageGRID 管理ネットワークに接続するノードの場合、このネットワーク用に作成された VMware ネットワークに関する以下の情報を収集する必要があります。

* ネットワーク名。
* IPアドレスを割り当てる方法（静的またはDHCP）。
+
** 静的IPアドレスを使用する場合は、各グリッドノードに必要なネットワークの詳細（IPアドレス、ゲートウェイ、ネットワークマスク）。
** DHCPを使用している場合は、グリッドネットワーク上のプライマリ管理ノードのIPアドレスを指定します。詳細については、link:how-grid-nodes-discover-primary-admin-node.html["グリッドノードがプライマリ管理ノードを検出する方法"]を参照してください。


* 管理ネットワークの外部サブネットリスト（ESL）。




[[client-network-information]]
== クライアントネットワーク情報

オプションの StorageGRID クライアントネットワークに接続するノードについては、このネットワーク用に作成された VMware ネットワークに関する次の情報を収集する必要があります。

* ネットワーク名。
* IPアドレスを割り当てる方法（静的またはDHCP）。
* 静的IPアドレスを使用する場合は、各グリッドノードに必要なネットワークの詳細（IPアドレス、ゲートウェイ、ネットワークマスク）。




[[information-about-additional-interfaces]]
== 追加インターフェースに関する情報

ノードをインストールした後、vCenter の VM にトランクまたはアクセスインターフェイスをオプションで追加できます。たとえば、管理ノードまたはゲートウェイノードにトランクインターフェイスを追加することで、VLAN インターフェイスを使用して、異なるアプリケーションやテナントに属するトラフィックを分離できます。または、高可用性（HA）グループで使用するアクセスインターフェイスを追加することもできます。

追加したインターフェースは、Grid Manager の VLAN インターフェースページと HA グループページに表示されます。

* トランクインターフェースを追加する場合は、新しい親インターフェースごとに1つ以上のVLANインターフェースを設定してください。link:../admin/configure-vlan-interfaces.html["VLANインターフェースを設定する"]を参照してください。
* アクセスインターフェースを追加する場合は、それをHAグループに直接追加する必要があります。link:../admin/configure-high-availability-group.html["高可用性グループを構成する"]を参照してください。




[[storage-volumes-for-virtual-storage-nodes]]
== 仮想ストレージノードのストレージボリューム

仮想マシンベースのストレージノードについては、以下の情報を収集する必要があります。

* 追加予定のストレージボリューム（ストレージLUN）の数とサイズ。link:storage-and-performance-requirements.html["ストレージとパフォーマンスの要件"]を参照してください。




[[grid-configuration-information]]
== グリッド構成情報

グリッドを構成するには、以下の情報を収集する必要があります。

* グリッドライセンス
* ネットワークタイムプロトコル（NTP）サーバーのIPアドレス
* DNSサーバーのIPアドレス
