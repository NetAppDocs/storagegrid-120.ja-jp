= StorageGRIDのすべてのLinuxホストにRPMまたはDEBパッケージをダウンロードしてインストールします
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID ノードが Linux ホストにデプロイされている場合は、アップグレードを開始する前に、これらの各ホストに追加の RPM または DEB パッケージをダウンロードしてインストールしてください。



[[download-upgrade-linux-and-hotfix-files]]
== アップグレード、Linux、およびホットフィックスファイルのダウンロード

Grid Manager から StorageGRID のアップグレードを実行する場合、最初のステップとしてアップグレードアーカイブと必要なホットフィックスをダウンロードするように求められます。ただし、Linux ホストをアップグレードするためにファイルをダウンロードする必要がある場合は、必要なファイルをすべて事前にダウンロードしておくことで時間を節約できます。

.手順
.  https://mysupport.netapp.com/site/products/all/details/storagegrid/downloads-tab["NetAppのダウンロード：StorageGRID"^]に進みます。
. 最新リリースをダウンロードするには、ボタンを選択するか、ドロップダウンメニューから別のバージョンを選択して*Go*を選択してください。
+
StorageGRID ソフトウェアのバージョンは、11._x.y_ という形式です。StorageGRID ホットフィックスの形式は次のとおりです：11._x.y.z_。

. ご利用の NetApp アカウントのユーザー名とパスワードでサインインしてください。
. 注意/MustRead通知が表示されたら、ホットフィックス番号をメモし、チェックボックスを選択してください。
. エンドユーザー使用許諾契約書（EULA）を読み、チェックボックスを選択してから、*同意して続行*を選択してください。
+
選択したバージョンのダウンロードページが表示されます。このページは3つの列で構成されています。

. 2列目（*StorageGRID のアップグレード*）から、2つのファイルをダウンロードします。
+
** 最新リリースのアップグレードアーカイブ（これは *VMware、SG1000、またはSG100プライマリ管理ノード* というラベルの付いたセクションにあるファイルです）。このファイルはアップグレードを実行するまで必要ありませんが、今ダウンロードしておくと時間を節約できます。
** RPM または DEB アーカイブ（ `.tgz`または `.zip`形式）。サービス用ノートパソコンで Windows を実行している場合は、 `.zip`ファイルを選択してください。
+
*** RHEL +
`StorageGRID-Webscale-_version_-RPM-_uniqueID_.zip` +
`StorageGRID-Webscale-_version_-RPM-_uniqueID_.tgz`
*** Ubuntu または Debian +
`StorageGRID-Webscale-_version_-DEB-_uniqueID_.zip` +
`StorageGRID-Webscale-_version_-DEB-_uniqueID_.tgz`




. 必要なホットフィックスのために注意/MustRead通知に同意する必要があった場合は、ホットフィックスをダウンロードしてください：
+
..  https://mysupport.netapp.com/site/products/all/details/storagegrid/downloads-tab["NetAppのダウンロード：StorageGRID"^]に戻る。
.. ドロップダウンリストからホットフィックス番号を選択してください。
.. 注意書きと使用許諾契約に再度同意してください。
.. ホットフィックスとそのREADMEファイルをダウンロードして保存してください。
+
アップグレードを開始すると、StorageGRID アップグレードページでホットフィックスファイルをアップロードするよう求められます。



. Linuxノードでは、コード署名の検証は手動で行われます。必要に応じて、インストールアーカイブを確認してください。
+
.. StorageGRID コード署名検証パッケージをダウンロードします。このパッケージのファイル名は `StorageGRID_<version-number>_Code_Signature_Verification_Package.tar.gz`の形式を使用します。ここで、 `<version-number>`は StorageGRID ソフトウェアバージョンです。
.. 手順に従ってlink:../swnodes/download-files-verify.html["インストールファイルを手動で検証する"]。






[[install-archive-on-all-linux-hosts]]
== すべてのLinuxホストにアーカイブをインストールします

StorageGRIDソフトウェアをアップグレードする前に、以下の手順を実行してください。

.手順
. インストールファイルからRPMまたはDEBパッケージを抽出します。
. すべてのLinuxホストにRPMまたはDEBパッケージをインストールしてください。
+
Linux への StorageGRID ホストサービスのインストール手順については、link:../swnodes/installing-storagegrid-webscale-host-services.html["StorageGRID ホストサービスのインストール"]を参照してください。

+
新しいパッケージは追加パッケージとしてインストールされます。





[[remove-installation-archives-for-previous-versions]]
== 以前のバージョンのインストールアーカイブを削除します

Linux ホストの空き容量を増やすには、不要になった以前のバージョンの StorageGRID のインストールアーカイブを削除できます。

.手順
. 古い StorageGRID インストールアーカイブを削除します。
