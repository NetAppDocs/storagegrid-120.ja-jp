= StorageGRID IP アドレスに関するガイドライン
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
IPアドレス変更ツールを使用してグリッドノードのIPアドレスを設定することで、ネットワーク構成を実行できます。

グリッド展開時に最初に設定されたネットワーク構成のほとんどの変更を行うには、Change IP ツールを使用する必要があります。標準的な Linux ネットワークコマンドとファイルを使用した手動変更は、すべての StorageGRID サービスに反映されない可能性があり、アップグレード、再起動、またはノード復旧手順を経ても設定が維持されない場合があります。


NOTE: IPアドレスの変更手順は、システムに影響を与える可能性のある手順です。新しい設定が適用されるまで、グリッドの一部が利用できなくなる可能性があります。


NOTE: グリッドネットワークサブネットリストのみを変更する場合は、グリッドマネージャを使用してネットワーク構成を追加または変更してください。それ以外の場合は、ネットワーク構成の問題によりグリッドマネージャにアクセスできない場合、またはグリッドネットワークのルーティング変更とその他のネットワーク変更を同時に実行している場合は、IP変更ツールを使用してください。


TIP: グリッド内のすべてのノードのグリッドネットワークIPアドレスを変更する場合は、link:changing-ip-addresses-and-mtu-values-for-all-nodes-in-grid.html["グリッド全体の変更に関する特別な手順"]を使用してください。



[[ethernet-interfaces]]
== イーサネットインターフェース

eth0に割り当てられるIPアドレスは、常にグリッドノードのグリッドネットワークIPアドレスです。eth1に割り当てられるIPアドレスは、常にグリッドノードの管理ネットワークIPアドレスです。eth2に割り当てられるIPアドレスは、常にグリッドノードのクライアントネットワークIPアドレスです。

一部のプラットフォーム（StorageGRID アプライアンスなど）では、eth0、eth1、eth2 は、物理インターフェースまたは VLAN インターフェースの下位ブリッジまたはボンディングで構成される集約インターフェースである場合があります。これらのプラットフォームでは、*SSM* > *リソース* タブに、eth0、eth1、eth2 に加えて、他のインターフェースに割り当てられたグリッド、管理、およびクライアントネットワークの IP アドレスが表示される場合があります。



[[dhcp]]
== DHCP

DHCPの設定は、導入フェーズでのみ可能です。設定時にDHCPを設定することはできません。グリッドノードのIPアドレス、サブネットマスク、およびデフォルトゲートウェイを変更する場合は、IPアドレス変更手順を使用する必要があります。IPアドレス変更ツールを使用すると、DHCPアドレスが静的になります。



[[high-availability-ha-groups]]
== 高可用性（HA）グループ

* クライアントネットワークインターフェイスがHAグループに含まれている場合、そのインターフェイスのクライアントネットワークIPアドレスを、HAグループ用に設定されたサブネット外のアドレスに変更することはできません。
* クライアントネットワークインターフェイスに設定されているHAグループに割り当てられている既存の仮想IPアドレスの値に、クライアントネットワークIPアドレスを変更することはできません。
* グリッドネットワークインターフェイスがHAグループに含まれている場合、そのインターフェイスのグリッドネットワークIPアドレスを、HAグループ用に構成されたサブネット外のアドレスに変更することはできません。
* グリッドネットワークのIPアドレスを、グリッドネットワークインターフェイスに設定されているHAグループに割り当てられている既存の仮想IPアドレスの値に変更することはできません。
