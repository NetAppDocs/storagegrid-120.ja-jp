= StorageGRIDにおけるプライマリまたは非プライマリ管理ノードの復旧
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
管理ノードの復旧プロセスは、それがプライマリ管理ノードであるか、非プライマリ管理ノードであるかによって異なります。

プライマリまたは非プライマリの管理ノードを復旧するための概要手順は同じですが、手順の詳細は異なります。

復旧する管理ノードに応じて、必ず正しい復旧手順に従ってください。手順は概要レベルでは同じように見えますが、詳細において違いがあります。
