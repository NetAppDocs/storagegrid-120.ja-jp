= 追加のStorageGRIDノードリカバリ手順を実行する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
交換ホスト上でStorageGRIDノードを稼働させるために実行した具体的な手順に応じて、各ノードに対して追加の復旧手順を実行する必要がある場合があります。

Linuxホストの交換時、または障害が発生したグリッドノードを新しいホストに復元する際に、何らかの是正措置を講じる必要がなかった場合、ノードの復旧は完了です。



[[corrective-actions-and-next-steps]]
== 是正措置と今後のステップ

ノード交換中に、以下のいずれかの是正措置を講じる必要があった場合があります。

* ノードをインポートするには、 `--force`フラグを使用する必要がありました。
* いかなる `<PURPOSE>`においても、 `BLOCK_DEVICE_<PURPOSE>`構成ファイル変数の値は、ホスト障害発生前と同じデータを含まないブロックデバイスを参照します。
* ノードに対して `storagegrid node force-recovery _node-name_`を発行しました。
* 新しいブロックデバイスを追加しました。


これらの是正措置のいずれかを実施した場合は、追加の復旧手順を実行する必要があります。
