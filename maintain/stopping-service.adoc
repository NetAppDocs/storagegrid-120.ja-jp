= StorageGRIDサービスを停止する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
メンテナンス手順によっては、グリッドノード上の他のサービスを稼働させたまま、単一のサービスを停止する必要がある場合があります。個々のサービスを停止するのは、メンテナンス手順で指示された場合に限ってください。

.開始する前に
あなたは `Passwords.txt`ファイルを持っています。

.タスク概要
これらの手順を使用してサービスを「管理者権限で停止」した場合、Server Manager はサービスを自動的に再起動しません。個々のサービスを手動で起動するか、Server Manager を再起動する必要があります。

ストレージノード上で LDR サービスを停止する必要がある場合、アクティブな接続が存在すると、サービスの停止に時間がかかる場合があることに注意してください。

.手順
. グリッドノードにログインします。
+
.. 次のコマンドを入力します： `ssh admin@_grid_node_IP_`
..  `Passwords.txt`ファイルに記載されているパスワードを入力してください。
.. 以下のコマンドを入力して root に切り替えます： `su -`
..  `Passwords.txt`ファイルに記載されているパスワードを入力してください。


+
rootとしてログインすると、プロンプトが `$`から `#`に変わります。

. 個別のサービスを停止する： `service _servicename_ stop`
+
次に例を示します。

+
[listing]
----
service ldr stop
----
+

NOTE: サービスの停止には最大11分かかる場合があります。

. コマンドシェルからログアウトします： `exit`
