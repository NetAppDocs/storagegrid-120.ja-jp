= StorageGRIDノードのメンテナンス手順
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
特定のグリッドノードまたはノードサービスに関連するメンテナンス手順を実行する必要がある場合があります。

ADC の移動:: link:../maintain/understanding-adc-service-quorum.html["ADC service（RSMサービス）"]は一部のストレージノードに配置されています。特定の廃止措置やノード変換の状況においては、ADCサービスを同一サイト内の別のストレージノードに移行する必要があります。
ストレージノードをデータ専用ノードに変換する:: ADCサービスを含まないストレージノードを、データ専用のストレージノードに変換できます。
ノードの再起動、シャットダウン、電源投入:: これらの手順は、1つまたは複数のノードを再起動したり、ノードをシャットダウンして再起動したり、ノードの電源をオフにしてから再びオンにしたりするために使用します。
ポートリマップ:: ポート再マッピング手順を使用すると、ノードからポート再マッピングを削除できます。たとえば、以前に再マッピングされたポートを使用してロードバランサーエンドポイントを設定する場合などに使用できます。
サーバーマネージャー:: Server Manager は、サービスの開始と停止を監視し、サービスが StorageGRID システムにスムーズに参加および離脱できるようにするため、すべてのグリッドノードで実行されます。Server Manager は各グリッドノード上のサービスを監視し、障害を報告したサービスを自動的に再起動しようとします。
+
--
サーバーマネージャの手順を実行するには、通常、ノードのコマンドラインにアクセスする必要があります。


CAUTION: サーバーマネージャーには、テクニカルサポートから指示があった場合にのみアクセスしてください。
