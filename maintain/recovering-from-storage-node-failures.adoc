= StorageGRIDストレージノードの障害から回復する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
障害が発生したストレージノードを復旧する手順は、障害の種類と、障害が発生したストレージノードの種類によって異なります。

この表を使用して、障害が発生したストレージノードの復旧手順を選択してください。

[cols="1a,1a,1a"]
|===
| 問題 | アクション | Notes 


 a| 
* 複数のストレージノードが故障しました。

 a| 
テクニカル サポートにお問い合わせください。
 a| 
複数のストレージノードを復旧すると、Cassandraデータベースの整合性に影響し、データ損失が発生する可能性があります。

テクニカルサポートは、2台目のストレージノードの復旧を開始しても安全な時期を判断できます。

*注*：1つのサイトでADCサービスを含むストレージノードが複数障害が発生した場合、そのサイトで保留中のプラットフォームサービスリクエストはすべて失われます。



 a| 
同一サイト内の複数のストレージノードで障害が発生したか、サイト全体で障害が発生しました。
 a| 
技術サポートにお問い合わせください。サイト復旧手順の実行が必要になる場合があります。
 a| 
テクニカルサポートがお客様の状況を評価し、復旧計画を作成します。link:how-site-recovery-is-performed-by-technical-support.html["テクニカルサポートがサイトを復旧する方法"]を参照してください。



 a| 
アプライアンスのストレージノードに障害が発生しました。
 a| 
link:recovering-storagegrid-appliance-storage-node.html["アプライアンスストレージノードを復旧する"]
 a| 
アプライアンスストレージノードの復旧手順は、すべての障害において同じです。



 a| 
1つ以上のストレージボリュームに障害が発生しましたが、システムドライブは正常です
 a| 
link:recovering-from-storage-volume-failure-where-system-drive-is-intact.html["システムドライブが無事な状態でストレージボリュームの障害から復旧する"]
 a| 
この手順は、ソフトウェアベースのストレージノードに使用されます。



 a| 
システムドライブに障害が発生しました。
 a| 
link:reviewing-warnings-for-system-drive-recovery.html["システムドライブ障害からの復旧"]
 a| 
ノードの交換手順は、展開プラットフォームと、ストレージボリュームにも障害が発生しているかどうかによって異なります。

|===

NOTE: いくつかのStorageGRID復旧手順では、Reaperを使用してCassandraの修復処理を行います。関連するサービスまたは必要なサービスが開始されるとすぐに、修復は自動的に行われます。スクリプトの出力に「reaper」または「Cassandra repair」という記述が見られる場合があります。修復が失敗したことを示すエラーメッセージが表示された場合は、エラーメッセージに示されているコマンドを実行してください。
