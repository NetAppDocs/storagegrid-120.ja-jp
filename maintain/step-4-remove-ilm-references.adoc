= StorageGRID のサイトへの ILM 参照を削除します
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
廃止サイトウィザードのステップ4（ILM参照の削除）では、ILMポリシーで使用されていない場合でも、サイトを参照している未使用のILMルールをすべて削除または編集する必要があります。

.手順
. 未使用のILMルールが当該サイトを参照しているかどうかを判断します。
+
ILMルールが記載されている場合、それらのルールはサイトを参照するものの、ポリシーには使用されません。

+

NOTE: StorageGRID がサイトを廃止すると、そのサイトを参照している未使用のイレイジャーコーディングプロファイルが自動的に無効化され、そのサイトを参照している未使用のストレージプールが自動的に削除されます。すべてのストレージノードのストレージプール（StorageGRID 11.6 以前）は、すべてのサイトを使用しているため削除されます。

. 使用されていないルールを編集または削除します：
+
** ルールを編集するには、ILMルールページに移動し、サイトを参照する消去コーディングプロファイルまたはストレージプールを使用するすべての配置を更新してください。次に、*ステップ4（ILM参照の削除）*に戻ります。
** ルールを削除するには、ゴミ箱アイコン image:icon_trash_can.png["アイコンゴミ箱"] を選択し、*OK* を選択します。
+

NOTE: サイトを廃止する前に、*コピーを2つ作成*ルールを削除する必要があります。



. 未使用のILMルールがサイトを参照していないこと、および*Next*ボタンが有効になっていることを確認してください。
. *Next* を選択します。
+

NOTE: 当該サイトを参照する残りのストレージプールおよびイレイジャーコーディングプロファイルは、サイトが削除されるとすべて無効になります。StorageGRID がサイトを廃止すると、そのサイトを参照している未使用のイレイジャーコーディングプロファイルが自動的に無効化され、そのサイトを参照している未使用のストレージプールが自動的に削除されます。All Storage Nodes ストレージプール（StorageGRID 11.6 以前）は、All Sites サイトを使用しているため削除されます。

+
ステップ5（ノードの競合を解決する）が表示されます。
