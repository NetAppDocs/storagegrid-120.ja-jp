= StorageGRID AdminノードまたはGatewayノードの運用停止に関する考慮事項
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
管理ノードまたはゲートウェイノードの廃止に関する考慮事項を確認してください。



[[considerations-for-admin-node]]
== 管理ノードに関する考慮事項

* プライマリ管理ノードを廃止することはできません。
* 管理ノードのネットワークインターフェイスのいずれかが高可用性（HA）グループの一部である場合、その管理ノードを廃止することはできません。まず、HAグループからネットワークインターフェイスを削除する必要があります。link:../admin/managing-high-availability-groups.html["HAグループの管理"]の手順を参照してください。
* 必要に応じて、管理ノードの廃止中にILMポリシーを安全に変更できます。
* 管理ノードを廃止し、StorageGRID システムでシングル サインオン（SSO）が有効になっている場合は、Active Directory Federation Services (AD FS) からノードの証明書利用者信頼を削除することを忘れないでください。
* link:../admin/grid-federation-overview.html["グリッドフェデレーション"]を使用する場合は、廃止するノードの IP アドレスがグリッド フェデレーション接続用に指定されていないことを確認してください。
* 接続が切断された管理ノードを廃止すると、そのノードの監査ログは失われますが、これらのログはプライマリ管理ノードにも存在しているはずです。




[[considerations-for-gateway-node]]
== ゲートウェイノードに関する考慮事項

* ゲートウェイノードのネットワークインターフェイスのいずれかが高可用性（HA）グループの一部である場合、そのゲートウェイノードを廃止することはできません。まず、HAグループからネットワークインターフェイスを削除する必要があります。link:../admin/managing-high-availability-groups.html["HAグループの管理"]の手順を参照してください。
* 必要に応じて、ゲートウェイノードの廃止中にILMポリシーを安全に変更できます。
* link:../admin/grid-federation-overview.html["グリッドフェデレーション"]を使用する場合は、廃止するノードの IP アドレスがグリッド フェデレーション接続用に指定されていないことを確認してください。
* ゲートウェイノードが切断されている状態であれば、安全に運用停止を行うことができます。
