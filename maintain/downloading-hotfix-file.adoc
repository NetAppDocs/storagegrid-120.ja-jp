= StorageGRIDホットフィックスファイルをダウンロードします
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ホットフィックスを適用するには、まずホットフィックスファイルをダウンロードする必要があります。

.手順
.  https://mysupport.netapp.com/site/products/all/details/storagegrid/downloads-tab["NetAppのダウンロード：StorageGRID"^]に進みます。
. *利用可能なソフトウェア*の下にある下向き矢印を選択すると、ダウンロード可能なホットフィックスの一覧が表示されます。
+

NOTE: ホットフィックスファイルのバージョンは、11.4__.x.y__ の形式です。

. アップデートに含まれる変更点を確認してください。
+

NOTE: 直前にlink:configuring-replacement-primary-admin-node.html["プライマリ管理ノードを復旧しました"]を実行した場合にホットフィックスを適用する必要があるときは、他のグリッドノードにインストールされているものと同じホットフィックスバージョンを選択してください。

+
.. ダウンロードするホットフィックスのバージョンを選択し、*Go* を選択します。
.. NetAppアカウントのユーザ名とパスワードを使用してサインインします。
.. エンドユーザー使用許諾契約書をよく読み、同意してください。
+
選択したバージョンのダウンロードページが表示されます。

.. ホットフィックス `readme.txt`ファイルをダウンロードすると、ホットフィックスに含まれる変更点の概要が表示されます。


. ホットフィックスのダウンロードボタンを選択し、ファイルを保存してください。
+

NOTE: このファイルの名前は変更しないでください。

+

NOTE: macOS デバイスを使用している場合、ホットフィックスファイルは自動的に `.txt`ファイルとして保存される場合があります。その場合は、 `.txt`拡張子を除いてファイル名を変更する必要があります。

. ダウンロード先を選択し、*保存*を選択します。
