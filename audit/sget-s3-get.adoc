= StorageGRIDにおけるS3 GETトランザクションのSGET監査メッセージ
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
S3クライアントがGETトランザクションを発行すると、オブジェクトを取得するか、バケット内のオブジェクトを一覧表示するか、バケット/オブジェクトのサブリソースを削除するリクエストが行われます。このメッセージは、トランザクションが成功した場合にサーバーから送信されます。

[cols="1a,1a,4a"]
|===
| Code | フィールド | 説明 


 a| 
CBID
 a| 
コンテンツブロック識別子
 a| 
要求されたコンテンツブロックの一意の識別子。CBIDが不明な場合は、このフィールドは0に設定されます。バケットに対する操作には、このフィールドは含まれません。



 a| 
CNCH
 a| 
一貫性制御ヘッダー
 a| 
リクエストにConsistency-Control HTTPリクエストヘッダーが存在する場合、その値。



 a| 
CNID
 a| 
接続識別子
 a| 
TCP/IP接続の一意のシステム識別子。



 a| 
CSIZ
 a| 
コンテンツサイズ
 a| 
取得したオブジェクトのサイズ（バイト単位）。バケットに対する操作には、このフィールドは含まれません。



 a| 
HTRH
 a| 
HTTPリクエストヘッダー
 a| 
設定時に選択された、ログに記録された HTTP リクエストヘッダー名と値のリスト。

 `X-Forwarded-For`はリクエストに存在し、かつ `X-Forwarded-For`の値がリクエスト送信者のIPアドレス（SAIP監査フィールド）と異なる場合、自動的に含まれます。



 a| 
LITY
 a| 
ListObjectsV2を使用したチャンク アップロード署名要求がサポートされるようになりました。
 a| 
_v2形式_の応答が要求されました。詳細については、 https://docs.aws.amazon.com/AmazonS3/latest/API/API_ListObjectsV2.html["AWS ListObjectsV2"^]を参照してください。GETバケット操作のみに適用されます。



 a| 
NCHD
 a| 
子供の数
 a| 
キーと共通プレフィックスが含まれます。GET バケット操作のみに適用されます。



 a| 
RANG
 a| 
範囲読み取り
 a| 
範囲読み取り操作専用です。このリクエストによって読み取られたバイト範囲を示します。スラッシュ（/）の後の値は、オブジェクト全体のサイズを示します。



 a| 
RSLT
 a| 
結果コード
 a| 
GETトランザクションの結果。結果は常に次のようになります：

SUCS：成功



 a| 
S3AIを使用したチャンク アップロード署名要求がサポートされるようになりました。
 a| 
S3テナントアカウントID（リクエスト送信者）
 a| 
リクエストを送信したユーザーのテナントアカウントID。空の値は、匿名アクセスを示します。



 a| 
S3AKを使用したチャンク アップロード署名要求がサポートされるようになりました。
 a| 
S3アクセスキーID（リクエスト送信者）
 a| 
リクエストを送信したユーザーのS3アクセスキーIDをハッシュ化したもの。空の値は、匿名アクセスを示します。



 a| 
S3BKを使用したチャンク アップロード署名要求がサポートされるようになりました。
 a| 
S3 バケット
 a| 
S3バケット名。



 a| 
S3KYを使用したチャンク アップロード署名要求がサポートされるようになりました。
 a| 
S3キー
 a| 
バケット名を含まない、S3キー名。バケットに対する操作には、このフィールドは含まれません。



 a| 
S3SRを使用したチャンク アップロード署名要求がサポートされるようになりました。
 a| 
S3 サブリソース
 a| 
操作対象のバケットまたはオブジェクトのサブリソース（該当する場合）。



 a| 
SACC
 a| 
S3テナントアカウント名（リクエスト送信者）
 a| 
リクエストを送信したユーザーのテナントアカウント名。匿名リクエストの場合は空欄です。



 a| 
SAIP
 a| 
IPアドレス（リクエスト送信元）
 a| 
リクエストを行ったクライアントアプリケーションのIPアドレス。



 a| 
SBAC
 a| 
S3テナントアカウント名（バケット所有者）
 a| 
バケット所有者のテナントアカウント名。クロスアカウントまたは匿名アクセスを識別するために使用されます。



 a| 
SBAI
 a| 
S3テナントアカウントID（バケット所有者）
 a| 
対象バケットの所有者のテナントアカウントID。クロスアカウントまたは匿名アクセスを識別するために使用します。



 a| 
SUSR
 a| 
S3ユーザーURN（リクエスト送信者）
 a| 
テナントアカウントIDと、リクエストを行ったユーザーのユーザー名。ユーザーはローカルユーザーまたはLDAPユーザーのいずれかです。例： `urn:sgws:identity::03393893651506583485:root`

匿名リクエストの場合は空欄です。



 a| 
時間
 a| 
Time
 a| 
リクエストの処理にかかった合計時間（マイクロ秒）。



 a| 
TLIP
 a| 
信頼できるロードバランサーのIPアドレス
 a| 
リクエストが信頼できるレイヤー7ロードバランサーによってルーティングされた場合、ロードバランサーのIPアドレス。



 a| 
TRNC
 a| 
切り捨てられたか、切り捨てられていないか
 a| 
すべての結果が返された場合は、false に設定します。返せる結果がさらにある場合は、true に設定します。GET バケット操作のみに適用されます。



 a| 
UUID
 a| 
汎用一意識別子
 a| 
StorageGRID システム内のオブジェクトの識別子。



 a| 
VSID
 a| 
バージョン ID
 a| 
要求されたオブジェクトの特定バージョンのバージョンID。バージョン管理されていないバケット内のバケットおよびオブジェクトに対する操作には、このフィールドは含まれません。

|===
