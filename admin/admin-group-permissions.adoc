= StorageGRID の管理者グループ権限
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
管理者ユーザーグループを作成する際、Grid Managerの特定の機能へのアクセスを制御するために、1つ以上の権限を選択します。その後、各ユーザーをこれらの管理者グループの1つ以上に割り当てることで、そのユーザーが実行できるタスクを決定できます。

各グループには少なくとも1つの権限を割り当てる必要があります。そうしないと、そのグループに属するユーザーは Grid Manager またはグリッド管理 API にサインインできなくなります。

デフォルトでは、少なくとも1つの権限を持つグループに属するユーザーは、以下のタスクを実行できます。

* グリッドマネージャーにサインインする
* ダッシュボードを表示する
* ノードページを表示する
* 現在発生しているアラートと解決済みのアラートを表示する
* 自分のパスワードを変更する（ローカルユーザーのみ）
* 構成およびメンテナンスページに記載されている特定の情報を表示する




[[interaction-between-permissions-and-access-mode]]
== 権限とアクセスモードの相互作用

すべての権限において、グループの*アクセスモード*設定によって、ユーザーが設定を変更したり操作を実行したりできるかどうか、または関連する設定や機能を表示することしかできないかどうかが決まります。ユーザーが複数のグループに所属していて、いずれかのグループが*読み取り専用*に設定されている場合、ユーザーは選択されたすべての設定と機能に対して読み取り専用アクセス権を持ちます。

以下のセクションでは、管理者グループの作成時または編集時に割り当てることができる権限について説明します。明示的に記載されていない機能を使用するには、*ルートアクセス*権限が必要です。



[[root-access]]
== ルート アクセス

この権限により、グリッド管理のすべての機能にアクセスできるようになります。



[[change-tenant-root-password]]
== テナントのルートパスワードを変更する

この権限により、テナントページの「ルートパスワードの変更」オプションにアクセスできるようになります。これにより、テナントのローカルルートユーザーのパスワードを変更できるユーザーを制御できます。この権限は、S3キーインポート機能が有効になっている場合に、S3キーを移行するためにも使用されます。この権限を持たないユーザーは、「ルートパスワードの変更」オプションを表示できません。


NOTE: 「テナント」ページ（*ルートパスワードの変更*オプションが含まれています）へのアクセスを許可するには、*テナントアカウント*権限も割り当ててください。



[[ilm]]
== ILM

この権限により、以下の *ILM* メニューオプションへのアクセスが可能になります：

* ルール
* ポリシー
* ポリシータグ
* ストレージプール
* ストレージグレード
* Regions
* オブジェクトメタデータ検索



NOTE: ストレージグレードを管理するには、ユーザーは「その他のグリッド構成」権限を持っている必要があります。



[[maintenance]]
== メンテナンス

これらのオプションを使用するには、ユーザーはメンテナンス権限を持っている必要があります。

* *設定* > *アクセス制御*：
+
** グリッドパスワード


* *設定* > *ネットワーク*：
+
** S3エンドポイントドメイン名


* *メンテナンス* > *タスク*：
+
** 運用停止
** 拡張
** オブジェクトの存在チェック
** リカバリ


* *メンテナンス* > *システム*：
+
** 復旧パッケージ
** ソフトウェアアップデート


* *サポート* > *ツール*：
+
** Logs




メンテナンス権限を持たないユーザーは、以下のページを閲覧することはできますが、編集することはできません：

* *メンテナンス* > *ネットワーク*：
+
** DNSサーバ
** グリッド ネットワーク
** NTPサーバ


* *メンテナンス* > *システム*：
+
** ライセンス


* *設定* > *ネットワーク*：
+
** S3エンドポイントドメイン名


* *設定* > *セキュリティ*：
+
** 証明書


* *設定* > *監視*：
+
** 監査とsyslogサーバ






[[manage-alerts]]
== アラートを管理する

この権限により、アラートを管理するためのオプションにアクセスできるようになります。ユーザーは、サイレンス、アラート通知、およびアラートルールを管理するために、この権限が必要です。



[[metrics-query]]
== メトリクスクエリ

この権限により、以下のものへのアクセスが可能になります：

* *サポート* > *ツール* > *メトリクス* ページ
* Grid Management API の *Metrics* セクションを使用したカスタム Prometheus メトリクス クエリ
* メトリクスを含むGrid Managerダッシュボードカード




[[object-metadata-lookup]]
== オブジェクトメタデータ検索

この権限により、*ILM* > *オブジェクトメタデータ検索* ページへのアクセスが可能になります。



[[other-grid-configuration]]
== その他のグリッド構成

この権限により、以下の追加のグリッド構成オプションにアクセスできます：

* *ILM*：
+
** ストレージグレード


* *設定* > *システム*：
* *サポート* > *その他*：
+
** リンクコスト






[[storage-appliance-administrator]]
== ストレージアプライアンス管理者

この権限により、以下が提供されます：

* グリッドマネージャを使用したストレージアプライアンス上の Eシリーズ SANtricity System Manager へのアクセス。
* これらの操作をサポートするアプライアンスの場合、「ドライブの管理」タブでトラブルシューティングおよびメンテナンス作業を実行できる機能。




[[tenant-accounts]]
== テナントアカウント

この権限により、以下のことが可能になります：

* テナントページにアクセスすると、テナントアカウントの作成、編集、削除を行うことができます。
* 既存のトラフィック分類ポリシーを表示する
* テナントの詳細を含む Grid Manager ダッシュボードカードを表示する
