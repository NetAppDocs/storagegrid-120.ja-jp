= StorageGRID S3 セットアップ ウィザードの考慮事項と要件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
S3 セットアップ ウィザードを使用して、StorageGRID を S3 アプリケーションのオブジェクトストレージシステムとして設定できます。



[[when-to-use-the-s3-setup-wizard]]
== S3 セットアップ ウィザードを使用するタイミング

S3 セットアップ ウィザードは、S3アプリケーションで使用するためのStorageGRIDの設定の各ステップをご案内します。ウィザードを完了する過程で、S3アプリケーションに値を入力するために使用できるファイルをダウンロードします。ウィザードを使用してシステムをより迅速に構成し、設定がStorageGRIDのベストプラクティスに準拠していることを確認してください。

もしあなたがlink:admin-group-permissions.html["ルートアクセス権限"]をお持ちの場合、StorageGRID Grid Manager の使用を開始する際に S3 セットアップ ウィザードを完了することも、後からいつでもウィザードにアクセスして完了させることもできます。要件に応じて、必要な項目の一部またはすべてを手動で設定し、その後ウィザードを使用して S3 アプリケーションに必要な値を組み立てることもできます。



[[before-using-the-wizard]]
== ウィザードを使用する前に

ウィザードを使用する前に、以下の前提条件を満たしていることを確認してください。

IPアドレスを取得し、VLANインターフェースを設定する:: 高可用性（HA）グループを構成する場合、S3 アプリケーションがどのノードに接続するか、およびどの StorageGRID ネットワークが使用されるかを把握しておく必要があります。サブネット CIDR、ゲートウェイ IP アドレス、仮想 IP（VIP）アドレスに入力する値についても把握しておく必要があります。
+
--
S3アプリケーションからのトラフィックを分離するために仮想LANを使用する予定であれば、VLANインターフェースは既に設定済みです。link:../admin/configure-vlan-interfaces.html["VLANインターフェースを設定する"]を参照してください。

--
IDフェデレーションとSSOを設定する:: IDフェデレーションを使用する予定がある場合、またはStorageGRIDシステムでシングル サインオン（SSO）を使用する予定がある場合は、これらの機能が有効になっています。また、S3アプリケーションが使用するテナントアカウントに対して、どのフェデレーショングループにルートアクセス権を付与するかも把握しておく必要があります。link:../admin/using-identity-federation.html["IDフェデレーションを使用する"]およびlink:../admin/how-sso-works.html["シングル サインオンを設定する"]を参照してください。
ドメイン名を取得して設定する:: StorageGRID に使用する完全修飾ドメイン名（FQDN）を把握しています。ドメインネームサーバー（DNS）のエントリは、このFQDNを、ウィザードを使用して作成したHAグループの仮想IP（VIP）アドレスにマッピングします。
+
--
S3仮想ホスト型リクエストを使用する予定がある場合は、link:../admin/configuring-s3-api-endpoint-domain-names.html["設定済みのS3エンドポイントドメイン名"]が必要です。仮想ホスト型のリクエストを使用することをお勧めします。

--
ロード バランシングとセキュリティ証明書の要件を確認する:: StorageGRID ロード バランシングを使用する予定がある場合は、ロード バランシングに関する一般的な考慮事項を確認済みであることを確認してください。アップロードする証明書、または証明書を生成するために必要な値を用意してください。
+
--
外部（サードパーティ）の ロード バランシング エンドポイントを使用する場合は、そのロード バランサーの完全修飾ドメイン名（FQDN）、ポート、および証明書が必要です。

--
グリッドフェデレーション接続を構成する:: S3テナントがアカウントデータをクローンし、グリッドフェデレーション接続を使用してバケットオブジェクトを別のグリッドに複製できるようにする場合は、ウィザードを開始する前に次の点を確認してください。
+
--
* link:grid-federation-manage-connection.html["グリッドフェデレーション接続を構成しました"]があります。
* 接続状態は「接続済み」です。
* ルートアクセス権限があります。
