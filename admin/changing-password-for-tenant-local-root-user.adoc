= StorageGRIDテナントのローカルルートユーザーのパスワードを変更する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
テナントのローカルルートユーザーがアカウントからロックアウトされた場合、ルートユーザーのパスワードを変更する必要が生じることがあります。

.開始する前に
* link:../admin/web-browser-requirements.html["対応ウェブブラウザ"] を使用して Grid Manager にサインインしています。
* link:admin-group-permissions.html["特定のアクセス権限"]があります。


.タスク概要
StorageGRID システムでシングル サインオン（SSO）が有効になっている場合、ローカルのルートユーザーはテナントアカウントにサインインできません。ルートユーザーのタスクを実行するには、ユーザーはテナントに対する Root access 権限を持つフェデレーショングループに所属している必要があります。

.手順
. 「テナント」を選択します。
+
image:tenant_accounts_page.png["テナントアカウントページ"]

. テナントアカウントを選択してください。以下のいずれかの方法を実行できます。
+
** テナントのチェックボックスを選択し、*Actions* > *Change root password* を選択します。
** テナント名を選択して詳細ページを表示し、*Actions* > *Change root password* を選択します。


. テナントアカウントの新しいパスワードを入力してください。
. * 保存 * を選択します。
