= StorageGRID ストレージ プロキシを設定する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
プラットフォームサービスまたはクラウドストレージプールを使用している場合は、ストレージノードと外部S3エンドポイントの間に非透過型プロキシ サーバを設定できます。例えば、プラットフォームサービスのメッセージをインターネット上のエンドポイントなどの外部エンドポイントに送信できるようにするには、非透過型プロキシ サーバが必要になる場合があります。


NOTE: 構成済みのストレージ プロキシ サーバ設定は、Kafka プラットフォームサービスのエンドポイントには適用されません。

.開始する前に
* link:admin-group-permissions.html["特定のアクセス権限"]があります。
* link:../admin/web-browser-requirements.html["対応ウェブブラウザ"] を使用して Grid Manager にサインインしています。


.タスク概要
単一のストレージ プロキシ サーバの設定を構成できます。

.手順
. *Configuration* ＞ *Security* ＞ *Proxy settings* を選択します。
. *[Storage]* タブで、*[Enable storage proxy]* チェックボックスを選択します。
. ストレージ プロキシ サーバのプロトコルを選択してください。
. プロキシ サーバのホスト名またはIPアドレスを入力してください。
. オプションで、プロキシ サーバへの接続に使用するポートを入力します。
+
このフィールドを空白のままにすると、プロトコルのデフォルトポートが使用されます（HTTP の場合は 80、SOCKS5 の場合は 1080）。

. * 保存 * を選択します。
+
ストレージ プロキシ サーバを保存した後、プラットフォームサービスまたはクラウドストレージプール用の新しいエンドポイントを設定およびテストできます。

+

NOTE: プロキシの変更が反映されるまで最大10分かかる場合があります。

. プロキシ サーバの設定を確認し、StorageGRID からのプラットフォームサービス関連のメッセージがブロックされないようにしてください。
. ストレージプロキシを無効にする必要がある場合は、チェックボックスをオフにして*保存*を選択してください。
