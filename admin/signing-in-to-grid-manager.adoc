= StorageGRID Grid Manager にサインインする
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
サポートされているWebブラウザのアドレスバーに、管理ノードの完全修飾ドメイン名（FQDN）またはIPアドレスを入力することで、Grid Managerのサインインページにアクセスします。

各 StorageGRID システムは、1つのプライマリ管理ノードと任意の数の非プライマリ管理ノードで構成されます。任意の管理ノードで Grid Manager にサインインして、StorageGRID システムを管理できます。ただし、一部のメンテナンス手順は、プライマリ管理ノードからのみ実行できます。



[[connect-to-ha-group]]
=== HAグループに接続する

管理ノードが高可用性（HA）グループに含まれている場合、HAグループの仮想IPアドレス、またはその仮想IPアドレスにマッピングされる完全修飾ドメイン名を使用して接続します。グループのプライマリインターフェースとしてプライマリ管理ノードを選択する必要があります。そうすることで、プライマリ管理ノードが利用できない場合を除き、グリッドマネージャにアクセスする際にはプライマリ管理ノード上でアクセスすることになります。link:managing-high-availability-groups.html["高可用性グループを管理する"]を参照してください。



[[use-sso]]
=== SSO を使用

サインインの手順は、link:how-sso-works.html["シングル サインオン（SSO）が設定されました"]場合、若干異なります。



[[sign-in-to-grid-manager-on-first-admin-node]]
== 最初の管理ノードでGrid Managerにサインインします

.開始する前に
* ログイン情報をお持ちです。
* あなたはlink:../admin/web-browser-requirements.html["対応ウェブブラウザ"]を使用しています。
* お使いのウェブブラウザでCookieが有効になっています。
* あなたは、少なくとも1つの権限を持つユーザーグループに属しています。
* グリッドマネージャーの URL をお持ちです：
+
`https://_FQDN_or_Admin_Node_IP_/`

+
完全修飾ドメイン名、管理ノードのIPアドレス、または管理ノードのHAグループの仮想IPアドレスを使用できます。

+
HTTPSのデフォルトポート（443）以外のポートでGrid Managerにアクセスするには、URLにポート番号を含めてください。

+
`https://_FQDN_or_Admin_Node_IP:port_/`

+

NOTE: 制限付きGrid ManagerポートではSSOは利用できません。ポート443を使用する必要があります。



.手順
. 対応ウェブブラウザを起動してください。
. ブラウザのアドレスバーに、Grid Manager の URL を入力します。
. セキュリティ警告が表示された場合は、ブラウザのインストールウィザードを使用して証明書をインストールしてください。link:using-storagegrid-security-certificates.html["セキュリティ証明書を管理する"]を参照してください。
. Grid Manager にサインインします。
+
表示されるサインイン画面は、StorageGRID にシングル サインオン（SSO）が設定されているかどうかによって異なります。

+
[role="tabbed-block"]
====
.SSOを使用していません
--
.. グリッドマネージャーのユーザー名とパスワードを入力してください。
.. 「サインイン」を選択します。


--
.SSOの使用
--
** StorageGRID が SSO を使用しており、このブラウザでこの URL に初めてアクセスする場合：
+
... 「サインイン」を選択します。アカウントフィールドは 0 のままにしておくことができます。
... 組織のSSOサインインページに、標準のSSO認証情報を入力してください。
+
例えば、StorageGRID が SSO を使用しており、以前に Grid Manager またはテナントアカウントにアクセスしたことがある場合：

+
.... *0*（グリッドマネージャーのアカウントID）を入力するか、最近使用したアカウントの一覧に*グリッドマネージャー*が表示されている場合は、それを選択してください。
.... 「サインイン」を選択します。
.... 組織のSSOサインインページで、通常のSSO認証情報を使用してサインインしてください。






--
====


ログインすると、ダッシュボードを含むグリッドマネージャーのホーム画面が表示されます。提供される情報については、link:../monitor/viewing-dashboard.html["ダッシュボードの表示と管理"]を参照してください。



[[sign-into-another-admin-node]]
== 別の管理ノードにサインインする

別の管理ノードにサインインするには、以下の手順に従ってください。

[role="tabbed-block"]
====
.SSOを使用していません
--
.手順
. ブラウザのアドレスバーに、もう一方の管理ノードの完全修飾ドメイン名またはIPアドレスを入力します。必要に応じてポート番号を含めてください。
. グリッドマネージャーのユーザー名とパスワードを入力してください。
. 「サインイン」を選択します。


--
.SSOの使用
--
StorageGRID が SSO を使用しており、1つの管理ノードにサインインしている場合、再度サインインすることなく他の管理ノードにアクセスできます。

.手順
. ブラウザのアドレスバーに、もう一方の管理ノードの完全修飾ドメイン名またはIPアドレスを入力してください。
. SSOセッションの有効期限が切れている場合は、再度認証情報を入力してください。


--
====
