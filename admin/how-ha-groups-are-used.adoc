= StorageGRID HA グループによる高可用性の提供方法
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
高可用性 （HA） グループを使用して、オブジェクトデータおよび管理用途向けに StorageGRID への高可用性接続を提供できます。

* HAグループは、グリッドマネージャーまたはテナントマネージャーへの高可用性の管理接続を提供できます。
* HAグループは、S3クライアントに対して高可用性のデータ接続を提供できます。
* インターフェースが1つだけのHAグループでは、複数のVIPアドレスを指定したり、IPv6アドレスを明示的に設定したりすることができます。


HAグループが高可用性を提供できるのは、グループに含まれるすべてのノードが同じサービスを提供する場合に限ります。HAグループを作成する際は、必要なサービスを提供するノードの種類からインターフェースを追加してください。

* *管理ノード*：ロードバランサーサービスを含め、グリッドマネージャーまたはテナントマネージャーへのアクセスを有効にします。
* *ゲートウェイノード*：ロードバランサーサービスを含めます。

[[limitations-of-using-ha-groups-with-grid-manager-or-tenant-manager]]
== Grid ManagerまたはTenant ManagerでHAグループを使用する際の制限事項

Grid ManagerまたはTenant Managerサービスに障害が発生した場合、HAグループのフェイルオーバーはトリガーされません。

フェールオーバーが発生した際に、グリッドマネージャーまたはテナントマネージャーにサインインしている場合、サインアウトされるため、作業を再開するには再度サインインする必要があります。

プライマリ管理ノードが利用できない場合、一部のメンテナンス手順は実行できません。フェイルオーバー中は、Grid Manager を使用して StorageGRID システムを監視できます。
