= StorageGRIDインターフェイスのセキュリティ設定を変更する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
インターフェースのセキュリティ設定では、ユーザーが指定された時間以上操作を行わない場合にログアウトするかどうか、および API エラー応答にスタックトレースを含めるかどうかを制御できます。

.開始する前に
* link:../admin/web-browser-requirements.html["対応ウェブブラウザ"] を使用して Grid Manager にサインインしています。
* link:admin-group-permissions.html["ルートアクセス権限"]があります。


.タスク概要
「セキュリティ設定」ページには、「ブラウザの非アクティブタイムアウト」と「管理 API スタックトレース」の設定が含まれています。

ブラウザの非アクティブタイムアウト:: ユーザーがサインアウトされるまでに、ブラウザが非アクティブ状態でいられる時間を示します。デフォルトは15分です。
+
--
ブラウザの非アクティブタイムアウトは、以下の要素によっても制御されます。

* システムセキュリティのために含まれている、別個の設定不可能な StorageGRID タイマーです。各ユーザーの認証トークンは、ユーザーがサインインしてから 16 時間後に期限切れになります。ユーザーの認証が期限切れになると、ブラウザの非アクティブタイムアウトが無効になっている場合や、ブラウザのタイムアウト値に達していない場合でも、そのユーザーは自動的にサインアウトされます。トークンを更新するには、ユーザーは再度サインインする必要があります。
* IDプロバイダーのタイムアウト設定（StorageGRID でシングル サインオン（SSO）が有効になっている場合を想定）。
+
SSO が有効になっていて、ユーザーのブラウザがタイムアウトした場合、ユーザーは StorageGRID に再度アクセスするために SSO 認証情報を再入力する必要があります。link:how-sso-works.html["SSOの動作"]を参照してください。



--
管理APIスタックトレース:: Grid ManagerおよびTenant Manager APIのエラー応答でスタックトレースを返すかどうかを制御します。
+
--
このオプションはデフォルトでは無効になっていますが、テスト環境でこの機能を有効にすることをお勧めします。一般的に、API エラーが発生した際に内部ソフトウェアの詳細が漏洩するのを避けるため、本番環境ではスタック トレースを無効にしておくことをお勧めします。

--


.手順
. *Configuration* > *Security* > *Security settings* を選択します。
. 「インターフェース」タブを選択します。
. ブラウザの非アクティブタイムアウトの設定を変更するには：
+
.. アコーディオンを展開します。
.. タイムアウト期間を変更するには、60秒から7日間の間の値を指定してください。デフォルトのタイムアウト時間は15分です。
.. この機能を無効にするには、チェックボックスの選択を解除してください。
.. * 保存 * を選択します。
+
この新しい設定は、現在ログインしているユーザーには影響しません。新しいタイムアウト設定を有効にするには、ユーザーは再度ログインするか、ブラウザを更新する必要があります。



. 管理 API スタック トレースの設定を変更するには：
+
.. アコーディオンを展開します。
.. Grid ManagerおよびTenant Manager APIのエラー応答にスタックトレースを返すには、このチェックボックスを選択してください。
+

CAUTION: APIエラーが発生した際に内部ソフトウェアの詳細が漏洩するのを防ぐため、本番環境ではスタックトレースを無効のままにしてください。

.. * 保存 * を選択します。
