= StorageGRID でストレージノード全体を管理
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージノードが容量に達したら、新しいストレージを追加してStorageGRIDシステムを拡張する必要があります。使用可能なオプションは3つあります：ストレージボリュームの追加、ストレージ拡張シェルフの追加、およびストレージノードの追加です。



[[add-storage-volumes]]
== ストレージボリュームを追加する

各ストレージノードは、最大数のストレージボリュームをサポートします。定義された最大値はプラットフォームによって異なります。ストレージノードに含まれるストレージボリュームの数が最大数に満たない場合、ボリュームを追加することで容量を増やすことができます。link:../expand/index.html["StorageGRID システムの拡張"]の手順を参照してください。



[[add-storage-expansion-shelves]]
== ストレージ拡張シェルフの追加

SG6060やSG6160などの一部のStorageGRIDアプライアンスストレージノードは、追加のストレージシェルフをサポートできます。拡張機能を備えたStorageGRIDアプライアンスをお持ちで、まだ最大容量まで拡張されていない場合は、ストレージシェルフを追加して容量を増やすことができます。link:../expand/index.html["StorageGRID システムの拡張"]の手順を参照してください。



[[add-storage-nodes]]
== ストレージノードを追加する

ストレージノードを追加することで、ストレージ容量を増やすことができます。ストレージを追加する際には、現在有効なILMルールおよび容量要件を慎重に検討する必要があります。link:../expand/index.html["StorageGRID システムの拡張"]の手順を参照してください。
