= StorageGRID プラットフォーム サービスについて学ぶ
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
プラットフォームサービスには、CloudMirror レプリケーション、イベント通知、および検索統合サービスが含まれます。

S3テナントアカウント向けにプラットフォームサービスを有効にする場合は、テナントがこれらのサービスを利用するために必要な外部リソースにアクセスできるように、グリッドを設定する必要があります。

プラットフォームサービスはlink:../tenant/what-is-branch-bucket.html["ブランチバケット"]ではサポートされていません。



[[cloudmirror-replication]]
== CloudMirror レプリケーション

StorageGRID CloudMirror レプリケーションサービスは、StorageGRID バケットの特定のオブジェクトを指定された外部宛先にミラーリングするために使用されます。

例えば、CloudMirror レプリケーションを使用して特定の顧客レコードを Amazon S3 にミラーリングし、AWS サービスを活用してデータの分析を実行することができます。

CloudMirrorレプリケーション機能には、クロスグリッドレプリケーション機能と重要な類似点と相違点がいくつかあります。詳細については、link:../admin/grid-federation-compare-cgr-to-cloudmirror.html["グリッド間レプリケーションとCloudMirrorレプリケーションの比較"]を参照してください。


NOTE: CloudMirror レプリケーションは、ソースバケットで S3 オブジェクトロックが有効になっている場合はサポートされません。



[[notifications]]
== 通知

バケットごとのイベント通知は、オブジェクトに対して実行された特定のアクションに関する通知を、指定された外部の Kafka クラスター、Webhook エンドポイント、または Amazon Simple Notification Service に送信するために使用されます。

例えば、バケットに追加された各オブジェクトについて、管理者にアラートを送信するように設定できます。ここでいうオブジェクトとは、重大なシステムイベントに関連付けられたログファイルを表します。


NOTE: S3オブジェクトロックが有効になっているバケットでイベント通知を設定することは可能ですが、オブジェクトのS3オブジェクトロックメタデータ（Retain Until DateやLegal Hold statusなど）は通知メッセージには含まれません。



[[search-integration-service]]
== 検索統合サービス

検索統合サービスは、S3オブジェクトのメタデータを指定されたElasticsearchインデックスに送信するために使用され、外部サービスを使用してメタデータを検索または分析できます。

例えば、バケットを設定して、S3オブジェクトのメタデータをリモートのElasticsearchサービスに送信するようにすることができます。その後、Elasticsearchを使用してバケット全体にわたる検索を実行したり、オブジェクトのメタデータに存在するパターンの高度な分析を実行したりすることができます。


NOTE: Elasticsearchとの連携はS3オブジェクトロックが有効になっているバケットで構成できますが、オブジェクトのS3オブジェクトロックメタデータ（Retain Until DateおよびLegal Holdステータスなど）は通知メッセージには含まれません。

プラットフォームサービスを利用することで、テナントは外部ストレージリソース、通知サービス、検索サービス、分析サービスなどを自身のデータに対して利用できるようになります。プラットフォームサービスのターゲットロケーションは通常、StorageGRID 環境の外部にあるため、テナントがこれらのサービスを利用することを許可するかどうかを決定する必要があります。その場合は、テナントアカウントを作成または編集する際に、プラットフォームサービスの使用を有効にする必要があります。テナントが生成するプラットフォームサービスメッセージが宛先に確実に届くように、ネットワークを構成する必要もあります。



[[recommendations-for-using-platform-services]]
== プラットフォームサービスの利用に関する推奨事項

プラットフォームサービスを使用する前に、以下の推奨事項に注意してください。

* StorageGRID システムの S3 バケットでバージョン管理と CloudMirror レプリケーションの両方が有効になっている場合は、宛先エンドポイントの S3 バケットのバージョン管理も有効にする必要があります。これにより、 CloudMirror レプリケーションがエンドポイント上で類似のオブジェクトバージョンを生成できるようになります。
* S3リクエストで CloudMirror レプリケーション、通知、および検索統合を必要とするアクティブなテナントを100個以上使用しないでください。アクティブなテナントが100を超えると、S3クライアントのパフォーマンスが低下する可能性があります。
* 完了できないエンドポイントへのリクエストは、最大500,000件までキューに格納されます。この制限は、アクティブなテナント間で均等に共有されます。新しいテナントはこの500,000の上限を一時的に超えることが認められており、新規作成されたテナントが不当に不利益を被ることがないようにしています。
