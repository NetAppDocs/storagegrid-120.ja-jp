= StorageGRID でメタデータ予約領域の設定を増やす
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージノードが特定の RAM および空き容量要件を満たしている場合、メタデータ予約領域のシステム設定を増やすことができる可能性があります。

.要件
* link:web-browser-requirements.html["対応ウェブブラウザ"] を使用して Grid Manager にサインインしています。
* あなたはlink:admin-group-permissions.html["ルートアクセス権限、またはその他のグリッド構成権限"]があります。


.タスク概要
システム全体のメタデータ予約領域の設定を、手動で最大 8 TB まで増やすことができる場合があります。

システム全体のメタデータ予約領域設定の値を増やすことができるのは、以下の2つの条件が両方とも満たされている場合のみです。

* お客様のシステム内のどのサイトにあるストレージノードも、それぞれ128 GB以上のRAMを搭載しています。
* システム内のどのサイトにあるストレージノードも、ストレージボリューム0に十分な空き容量があります。


この設定値を上げると、同時にすべてのストレージノードのストレージボリューム 0 におけるオブジェクトストレージに使用できる容量が減少することに注意してください。そのため、想定されるオブジェクトメタデータの要件に基づいて、メタデータ予約領域を 8 TB より小さい値に設定することをお勧めします。


NOTE: 一般的には、低い値よりも高い値を使用する方が適切です。メタデータ予約領域の設定値が大きすぎる場合は、後で小さくすることができます。一方、後で値を増やすと、システムは空き容量を確保するためにオブジェクトデータを移動する必要が生じる場合があります。

メタデータ予約領域の設定が、特定のストレージノード上のオブジェクトメタデータストレージに許可される領域にどのように影響するかについての詳細な説明については、link:managing-object-metadata-storage.html["オブジェクトメタデータストレージの管理"]を参照してください。

.手順
. 現在のメタデータ予約領域の設定を確認します。
+
.. *Configuration* > *System* > *Storage settings* を選択します。
.. *メタデータ予約領域*の値を確認してください。


. この値を増やすには、各ストレージノードのストレージボリューム0に十分な空き容量があることを確認してください。
+
.. * Nodes * を選択します。
.. グリッド内の最初のストレージノードを選択してください。
.. 「ストレージ」タブを選択します。
.. 「ボリューム」セクションで、*/var/local/rangedb/0* というエントリを探します。
.. 利用可能な値が、使用したい新しい値と現在のメタデータ予約領域の値との差以上であることを確認してください。
+
例えば、メタデータ予約領域の設定が現在 4 TB で、それを 6 TB に増やしたい場合、使用可能な値は 2 TB 以上である必要があります。

.. すべてのストレージノードに対して、これらの手順を繰り返してください。
+
*** 1つ以上のストレージノードに十分な空き容量がない場合、メタデータ予約容量の値を増やすことはできません。この手順を続行しないでください。
*** 各ストレージノードのボリューム0に十分な空き容量がある場合は、次のステップに進みます。




. 各ストレージノードには、少なくとも128 GB のRAMが搭載されていることを確認してください。
+
.. * Nodes * を選択します。
.. グリッド内の最初のストレージノードを選択してください。
.. 「ハードウェア」タブを選択します。
.. メモリ使用量グラフにカーソルを合わせてください。*合計メモリ*が 128 GB 以上であることを確認してください。
.. すべてのストレージノードに対して、これらの手順を繰り返してください。
+
*** 1つ以上のストレージノードに十分な合計メモリ容量がない場合、メタデータ予約領域の値を増やすことはできません。この手順を続行しないでください。
*** 各ストレージノードの合計メモリ容量が128 GB以上であれば、次のステップに進みます。




. メタデータ予約領域の設定を更新します。
+
.. *Configuration* > *System* > *Storage settings* を選択します。
.. 「Metadata Reserved Space」を選択してください。
.. 新しい値を入力してください。
+
例えば、サポートされている最大値である8 TBを入力するには、*8000000000000*（8の後にゼロが12個続く）と入力します。

.. * 保存 * を選択します。
