= StorageGRIDクライアント接続のIPアドレスとポート
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
オブジェクトを保存または取得するために、S3クライアントアプリケーションは、すべての管理ノードとゲートウェイノードに含まれているロードバランサーサービス、またはすべてのストレージノードに含まれているローカルディストリビューションルーター（LDR）サービスに接続します。

クライアントアプリケーションは、グリッドノードのIPアドレスとそのノード上のサービスのポート番号を使用して StorageGRID に接続できます。オプションとして、仮想IP（VIP）アドレスを使用する高可用性接続を提供するために、ロードバランシングノードの高可用性（HA）グループを作成できます。IPアドレスやVIPアドレスの代わりに完全修飾ドメイン名（FQDN）を使用して StorageGRID に接続する場合は、DNSエントリを設定できます。

この表は、クライアントが StorageGRID に接続できるさまざまな方法と、各接続タイプで使用される IP アドレスおよびポートをまとめたものです。ロードバランサーエンドポイントと高可用性（HA）グループを既に作成している場合は、<<IPアドレスを見つける場所>>を参照して、Grid Manager でこれらの値を確認してください。

[[example-urls]]
== URLの例

クライアントアプリケーションをゲートウェイノードのHAグループのロードバランサーエンドポイントに接続するには、以下に示すような構造のURLを使用します。

`https://_VIP-of-HA-group:LB-endpoint-port_`

例えば、HAグループの仮想IPアドレスが192.0.2.5で、ロードバランサーエンドポイントのポート番号が10443の場合、アプリケーションは次のURLを使用してStorageGRIDに接続できます：

`\https://192.0.2.5:10443`



[[where-to-find-ip-addresses]]
== IPアドレスを見つける場所

. グリッドマネージャーにlink:../admin/web-browser-requirements.html["対応ウェブブラウザ"]を使用してサインインします。
. グリッドノードのIPアドレスを確認するには：
+
.. * Nodes * を選択します。
.. 接続先の管理ノード、ゲートウェイノード、またはストレージノードを選択してください。
.. * Overview *タブを選択します。
.. ノード情報セクションで、ノードのIPアドレスをメモしてください。
.. IPv6アドレスとインターフェースのマッピングを表示するには、*詳細を表示*を選択してください。
+
クライアントアプリケーションから、リストにある任意のIPアドレスに接続を確立できます。

+
*** *eth0:* グリッドネットワーク
*** *eth1:* 管理ネットワーク（オプション）
*** *eth2:* クライアントネットワーク（オプション）
+

NOTE: 管理ノードまたはゲートウェイノードを表示していて、それが高可用性グループのアクティブノードである場合、HAグループの仮想IPアドレスがeth2に表示されます。





. 高可用性グループの仮想IPアドレスを確認するには：
+
.. *Configuration* > *Network* > *High availability groups* を選択します。
.. 表で、HAグループの仮想IPアドレスを確認します。


. ロードバランサーのエンドポイントのポート番号を調べるには：
+
.. *設定* ＞ *ネットワーク* ＞ *ロード バランシング エンドポイント* を選択します。
.. 使用したいエンドポイントのポート番号をメモしておいてください。
+

NOTE: ポート番号が80または443の場合、エンドポイントはゲートウェイノードでのみ構成されます。これは、これらのポートが管理ノードで予約されているためです。その他のポートはすべて、ゲートウェイノードと管理ノードの両方で設定されます。

.. 表からエンドポイントの名前を選択してください。
.. クライアントタイプ（S3）が、エンドポイントを使用するクライアントアプリケーションと一致していることを確認してください。
