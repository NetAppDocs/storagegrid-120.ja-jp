= StorageGRID 拡張後にストレージノードがアクティブであることを確認する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
新しいストレージノードを追加する拡張操作が完了すると、StorageGRID システムは自動的に新しいストレージノードの使用を開始します。StorageGRID システムを使用して、新しいストレージノードがアクティブであることを確認する必要があります。

.手順
. グリッドマネージャーにlink:../admin/web-browser-requirements.html["対応ウェブブラウザ"]を使用してサインインします。
. 「ノード」>「_拡張ストレージノード_」>「ストレージ」を選択します。
. *ストレージ使用量 - オブジェクトデータ* グラフにカーソルを合わせると、*使用量* の値が表示されます。これは、オブジェクトデータに使用されている総使用可能容量の量です。
. グラフ上でカーソルを右に移動させると、*Used* の値が増加していることを確認してください。
