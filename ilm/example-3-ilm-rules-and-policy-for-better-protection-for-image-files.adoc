= StorageGRIDで画像ファイルを保護するためのILMルールとポリシー
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
以下のルールとポリシーの例を使用することで、1 MBを超えるオブジェクトにはイレイジャー コーディングが適用され、それより小さいオブジェクトには2つのコピーが作成されるように設定できます。


CAUTION: 以下のILMルールおよびポリシーは、あくまで例です。ILMルールを設定する方法は数多くあります。新しいポリシーを有効にする前に、シミュレーションを実行して、意図したとおりに機能し、コンテンツの損失を防ぐことができることを確認してください。



[[ilm-rule-1-for-example-3-use-ec-for-image-files-greater-than-1-mb]]
== ILMルール1（例3）：1 MBを超える画像ファイルにはECを使用する

このILMルールの例では、高度なフィルタリングを使用して、1 MBを超えるすべての画像ファイルにイレイジャー コーディングを適用します。


NOTE: イレイジャー コーディングは、1 MB を超えるオブジェクトに最適です。非常に小さなイレイジャー コーディング フラグメントを管理するオーバーヘッドを回避するために、200 KB 未満のオブジェクトにはイレイジャー コーディングを使用しないでください。

|===
| ルール定義 | 例の値 


 a|

 a|

 a|

 a|

 a|

|===
image:policy_3_rule_1_ec_images_adv_filtering.png["ILMルール1（例3）：1 MBを超える画像ファイルにはECを使用する"]

このルールはポリシーの最初のルールとして設定されているため、イレイジャー コーディングのデータ配置指示は、1 MBを超える.jpgおよび.pngファイルにのみ適用されます。



[[ilm-rule-2-for-example-3-create-2-replicated-copies-for-all-remaining-image-files]]
== ILMルール2（例3）：残りのすべての画像ファイルに対してレプリケートコピーを2つ作成する

このILMルールの例では、高度なフィルタリングを使用して、より小さな画像ファイルを複製するように指定しています。ポリシーの最初のルールですでに1 MBを超える画像ファイルが対象となっているため、このルールは1 MB以下の画像ファイルに適用されます。

[[ilm-policy-for-example-3-better-protection-for-image-files]]
== ILMポリシーの例3：画像ファイルの保護強化

このILMポリシーの例には、次の3つのルールが含まれています。

* 最初のルールでは、1 MBを超えるすべての画像ファイルにイレイジャー コーディングを適用します。
* 2つ目のルールは、残りの画像ファイル（つまり、1 MB以下の画像ファイル）のコピーを2つ作成します。
* デフォルトルールは、残りのすべてのオブジェクト（つまり、画像ファイル以外のすべてのファイル）に適用されます。
