= StorageGRIDにおける単一コピー複製のリスク
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
複製コピーを作成するための ILM ルールを作成する場合、配置手順において任意の期間に対して少なくとも 2 つのコピーを指定する必要があります。


NOTE: いかなる期間においても複製コピーを1つだけ作成するようなILMルールは使用しないでください。オブジェクトの複製コピーが1つしか存在しない場合、ストレージノードが故障したり、重大なエラーが発生したりすると、そのオブジェクトは失われます。アップグレードなどのメンテナンス手順中は、一時的にオブジェクトへのアクセスができなくなる場合もあります。

次の例では、Make 1 Copy ILMルールにより、オブジェクトの複製コピーが1つ、3つのストレージノードを含むストレージプールに配置されるように指定されています。このルールに一致するオブジェクトが取り込まれると、StorageGRIDは単一のコピーを1つのストレージノードにのみ配置します。

image:ilm_replication_make_1_copy.png["ILMレプリケーション コピーを1つ作成"]

ILMルールがオブジェクトの複製コピーを1つだけ作成する場合、ストレージノードが利用不能になると、そのオブジェクトにアクセスできなくなります。この例では、ストレージノード2がオフラインになった場合（アップグレードやその他のメンテナンス手順中など）、オブジェクトAAAへのアクセスが一時的に失われます。ストレージノード2が故障した場合、オブジェクトAAAは完全に失われます。

image:ilm_replication_make_1_copy_sn_fails.png["ILMレプリケーション1コピー作成SN失敗"]

オブジェクトデータの損失を防ぐため、レプリケーションで保護したいすべてのオブジェクトについて、常に少なくとも2つのコピーを作成する必要があります。2つ以上のコピーが存在する場合、Storage Nodeのいずれかが故障したりオフラインになったりしても、オブジェクトにアクセスできます。

image:ilm_replication_make_2_copies_sn_fails.png["ILMレプリケーション2コピー作成SN失敗"]
