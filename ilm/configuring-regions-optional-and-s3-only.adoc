= StorageGRID の S3 リージョンを設定する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ILMルールを使用すると、S3バケットが作成されるオプションのリージョンに基づいてオブジェクトをフィルタリングできるため、異なるリージョンのオブジェクトを異なるストレージ場所に保存できます。

S3バケットのリージョンをルール内のフィルタとして使用する場合は、まずシステム内のバケットで使用できるリージョンを作成する必要があります。


NOTE: バケットが作成された後は、バケットのリージョンを変更することはできません。

.開始する前に
* link:../admin/web-browser-requirements.html["対応ウェブブラウザ"] を使用して Grid Manager にサインインしています。
* link:../admin/admin-group-permissions.html["特定のアクセス権限"]があります。


.タスク概要
S3バケットを作成する際、バケットを特定のリージョンに作成するように指定できます。リージョンを指定することで、バケットをユーザーの地理的に近い場所に配置でき、レイテンシの最適化、コストの最小化、および規制要件への対応に役立ちます。

ILMルールを作成する際、S3バケットに関連付けられたリージョンを高度なフィルタとして使用できます。例えば、 `us-west-2`リージョンで作成されたS3バケット内のオブジェクトにのみ適用されるルールを設計できます。その後、それらのオブジェクトのコピーを、そのリージョン内のデータセンターサイトにあるStorage Nodeに配置するように指定することで、レイテンシを最適化できます。

リージョンを設定する際は、以下のガイドラインに従ってください。

* デフォルトでは、すべてのバケットは `us-east-1`リージョンに属するとみなされます。
* テナントマネージャまたはテナント管理 API を使用してバケットを作成する際にデフォルト以外のリージョンを指定する場合、または S3 PUT Bucket API リクエストの LocationConstraint リクエスト要素を使用する場合は、事前にグリッドマネージャを使用してリージョンを作成しておく必要があります。PUT Bucket リクエストで StorageGRID に定義されていないリージョンを使用すると、エラーが発生します。
* S3バケットを作成する際は、正確なリージョン名を使用する必要があります。リージョン名は大文字と小文字を区別します。使用可能な文字は、数字、英字、ハイフンです。
+

NOTE: EUはeu-west-1の別名とはみなされていません。EUまたはeu-west-1リージョンを使用する場合は、正確な名前を使用する必要があります。

* いずれかのポリシー（アクティブまたは非アクティブ）に割り当てられているルールで使用されているリージョンは、削除または変更できません。
* ILMルールで無効なリージョンを詳細フィルタとして使用した場合、そのルールをポリシーに追加することはできません。
+
ILMルールで領域を高度なフィルタとして使用した後にその領域を削除した場合、またはGrid Management APIを使用してルールを作成し、定義していない領域を指定した場合に、無効な領域が発生する可能性があります。

* S3バケットを作成するために使用したリージョンを削除した場合、そのバケット内のオブジェクトを検索するためにLocation Constraintの詳細フィルターを使用したい場合は、そのリージョンを再度追加する必要があります。


.手順
. *ILM* > *リージョン*を選択します。
+
地域ページが表示されます。

. 「すべての地域」または「デフォルトの地域」タブを選択してください。
+
[role="tabbed-block"]
====
.全地域
--
「すべての地域」タブには、定義済みのデフォルト地域を含む、現在定義されている地域が表示されます。


NOTE: *すべての地域*タブでは、デフォルトの地域を削除または変更することはできません。デフォルトの地域を変更するには、*デフォルトの地域*タブを使用してください。

.. 地域を追加するには、*別の地域を追加*を選択してください。
.. S3バケットを作成する際に使用するリージョン名を入力してください。
+
対応するS3バケットを作成する際には、この正確なリージョン名をLocationConstraintリクエスト要素として使用する必要があります。

.. 使用されていない領域を削除するには、削除アイコン image:icon-x-to-remove.png["アイコンを削除"] を選択します。
+
現在いずれかのポリシー（有効または無効を問わず）で使用されている領域を削除しようとすると、エラーメッセージが表示されます。

.. 変更が完了したら、*保存*を選択してください。
+
これらのリージョンは、ILM ルール作成ウィザードのステップ 1 にある「詳細フィルター」セクションから選択できるようになりました。link:create-ilm-rule-enter-details.html#use-advanced-filters-in-ilm-rules["ILMルールで高度なフィルターを使用する"]を参照してください。



--
.デフォルトリージョン
--
「デフォルトリージョン」タブには、現在定義されているデフォルトリージョンが表示され、変更することができます。

.. デフォルトのリージョンを変更するには、*デフォルトリージョン*ドロップダウンリストに表示されるオプションからリージョン名を選択してください。
.. * 保存 * を選択します。
