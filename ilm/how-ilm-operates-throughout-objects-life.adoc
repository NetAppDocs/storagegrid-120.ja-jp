= StorageGRID でオブジェクトのライフサイクル全体を通じて ILM がどのように動作するか
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
StorageGRID が ILM を使用してオブジェクトのライフサイクルのあらゆる段階を管理する方法を理解することで、より効果的なポリシーを設計できます。

* *取り込み*：取り込みは、S3クライアントアプリケーションがStorageGRIDシステムにオブジェクトを保存するための接続を確立したときに開始され、StorageGRIDがクライアントに「取り込み成功」メッセージを返したときに完了します。オブジェクトデータは、ILM要件の指定方法に応じて、ILM指示を即座に適用する（同期配置）か、中間コピーを作成して後でILMを適用する（デュアルコミット）かのいずれかの方法で、取り込み中に保護されます。
* *コピー管理*：ILMの配置指示で指定された数と種類のオブジェクトコピーを作成した後、StorageGRIDはオブジェクトの位置を管理し、オブジェクトの紛失を防ぎます。
+
** *ILM スキャンと評価*：StorageGRID はグリッドに格納されているオブジェクトのリストを継続的にスキャンし、現在のコピーが ILM の要件を満たしているかどうかを確認します。オブジェクトのコピーの種類、数、または場所が異なる場合、StorageGRID は必要に応じてコピーを作成、削除、または移動します。
** *バックグラウンド検証*：StorageGRID は、オブジェクトデータの整合性を確認するために、バックグラウンド検証を継続的に実行します。問題が見つかった場合、StorageGRID は現在の ILM 要件を満たす場所に、新しいオブジェクトコピーまたは置換用のイレイジャー コーディング オブジェクトフラグメントを自動的に作成します。参照：link:../troubleshoot/verifying-object-integrity.html["オブジェクトの整合性を確認する"]


* *オブジェクトの削除*：オブジェクトの管理は、すべてのコピーが StorageGRID システムから削除されたときに終了します。オブジェクトは、クライアントからの削除要求、ILM による削除、または S3 バケットのライフサイクルの期限切れによる削除の結果として削除されることがあります。
+

NOTE: S3オブジェクトロックが有効になっているバケット内のオブジェクトは、法的保留中の場合、または保持期限が指定されているもののまだ到来していない場合は削除できません。
