= StorageGRID でストレージグレードを作成して割り当てる
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージグレードは、ストレージノードで使用されるストレージの種類を識別します。ILMルールによって特定のオブジェクトを特定のストレージノードに配置する場合は、ストレージグレードを作成できます。

.開始する前に
* link:../admin/web-browser-requirements.html["対応ウェブブラウザ"] を使用して Grid Manager にサインインしています。
* link:../admin/admin-group-permissions.html["特定のアクセス権限"]があります。


.タスク概要
初めて StorageGRID をインストールすると、*デフォルト* ストレージグレードがシステム内のすべてのストレージノードに自動的に割り当てられます。必要に応じて、カスタムストレージグレードを定義し、異なるストレージノードに割り当てることができます。

カスタムストレージグレードを使用すると、特定の種類のストレージノードのみを含むILMストレージプールを作成できます。たとえば、StorageGRID オールフラッシュ ストレージアプライアンスなど、最も高速なストレージノードに特定のオブジェクトを保存することができます。


NOTE: メタデータ専用のストレージノードには、ストレージグレードを割り当てることはできません。詳細については、link:../primer/what-storage-node-is.html#types-of-storage-nodes["ストレージノードの種類"]を参照してください。

ストレージグレードが問題にならない場合（たとえば、すべてのストレージノードが同一である場合）、この手順をスキップして、link:creating-storage-pool.html["ストレージプールを作成する"]の際にストレージグレードに「すべてのストレージグレードを含む」オプションを使用できます。この選択方法を使用すると、ストレージグレードに関係なく、サイト内のすべてのストレージノードがストレージプールに含まれることが保証されます。


NOTE: 必要以上にストレージグレードを作成しないでください。例えば、Storage Nodeごとにストレージグレードを作成しないでください。代わりに、各ストレージグレードを2つ以上のノードに割り当ててください。ストレージグレードが1つのノードのみに割り当てられている場合、そのノードが利用不能になった際にILMのバックログが発生する可能性があります。

.手順
. *ILM* ＞ *Storage grades* を選択します。
. カスタムストレージグレードを定義する：
+
.. 追加するカスタムストレージグレードごとに、*挿入* image:icon_nms_insert.gif["アイコンを挿入"] を選択して行を追加します。
.. 説明的なラベルを入力してください。
+
image:editing_storage_grades.gif["ストレージグレードページ"]

.. 「変更を適用」を選択します。
.. 必要に応じて、保存済みのラベルを変更する場合は、*編集* image:icon_nms_edit.gif["編集アイコン"] を選択し、*変更を適用* を選択します。
+

NOTE: ストレージグレードは削除できません。



. ストレージノードに新しいストレージグレードを割り当てます：
+
.. LDRリストからストレージノードを探し、その*編集*アイコンimage:icon_nms_edit.gif["編集アイコン"]を選択します。
.. リストから適切なストレージグレードを選択してください。
+
image:assigning_storage_grades_to_storage_nodes.gif["ストレージグレードページ"]

+

NOTE: ストレージグレードは、特定のストレージノードに一度だけ割り当ててください。障害から復旧したストレージノードは、以前に割り当てられたストレージグレードを維持します。ILMポリシーが有効になった後は、この割り当てを変更しないでください。割り当てが変更された場合、データは新しいストレージグレードに基づいて保存されます。

.. 「変更を適用」を選択します。
